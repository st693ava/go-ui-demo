Instalação

go-ui distribui-se como um único bundle ESM auto-contido (Vue + Reka embutidos). Não precisas de bundler nem de framework no consumidor — um import regista os 48+ Custom Elements.

Escolhe o teu ambiente

📦npm / git 🌐HTML puro ⚡Vite / SPA 🔺Laravel 🚀Astro

Instala directamente do repositório privado:

npm i github:st693ava/go-ui-web-components

No teu entry-point, importa o registo uma vez:

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Já podes usar qualquer elemento no HTML:

<go-button>Olá</go-button>
<go-input name="email" type="email"></go-input>

Sem build. Aponta para o bundle e o CSS:

<link rel="stylesheet" href="go-ui.css" />
<script type="module" src="go-ui.js"></script>

<go-card card-title="Pronto">Funciona em HTML puro.</go-card>
Os componentes pesados (go-chart, go-data-table) chegam em chunks lazy ao lado do go-ui.js — serve a pasta dist/ inteira.

Em qualquer SPA (Vue, React, Svelte, vanilla):

npm i github:st693ava/go-ui-web-components
// src/main.ts
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Os Custom Elements não colidem com o framework — são light-DOM e o estado vive em Reka, não no teu runtime.

Via Vite do Laravel (resources/js/app.js):

import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Usa os elementos directamente nas Blade views. Os inputs são FACE, por isso integram-se em <form> e no request normal do Laravel sem JS adicional.

Importa o registo num script de cliente:

---
// Layout.astro
---
<script>
  import '@st693ava/go-ui'
</script>
<link rel="stylesheet" href="/node_modules/@st693ava/go-ui/dist/go-ui.css" />

Tema light / dark

O tema resolve-se por uma classe .dark no <html> e tokens OKLCH. Default = sistema. Alterna no canto superior direito desta página.
