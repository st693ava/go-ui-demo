Spinner

Um indicador que pode ser usado para mostrar um estado de carregamento.

Anterior Skeleton Seguinte Progress
A processar pagamento 
<go-button disabled>
  <go-spinner></go-spinner>
  A processar pagamento
</go-button>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-spinner> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Coloca <go-spinner> em qualquer sítio onde precises de sinalizar atividade. Por defeito tem o tamanho size-4 e herda a cor do texto via currentColor. 

<go-spinner></go-spinner>
<go-spinner></go-spinner>

Exemplos

Tamanho

Usa o atributo size (xs, sm, md, lg, xl) para alterar a dimensão do spinner. 

<go-spinner size="xs"></go-spinner>
<go-spinner size="sm"></go-spinner>
<go-spinner size="md"></go-spinner>
<go-spinner size="lg"></go-spinner>

Cor

Usa uma classe utilitária text-* no host para alterar a cor do spinner — ele herda currentColor. 

<go-spinner size="md" class="text-red-500"></go-spinner>
<go-spinner size="md" class="text-green-500"></go-spinner>
<go-spinner size="md" class="text-blue-500"></go-spinner>
<go-spinner size="md" class="text-yellow-500"></go-spinner>
<go-spinner size="md" class="text-purple-500"></go-spinner>

Botão

Adiciona um spinner a um botão para indicar um estado de carregamento. O <go-button> trata do espaçamento entre o spinner e o texto.

A carregar... Aguarda A processar 
<go-button disabled size="sm">
  <go-spinner></go-spinner>
  A carregar...
</go-button>
<go-button variant="outline" disabled size="sm">
  <go-spinner></go-spinner>
  Aguarda
</go-button>
<go-button variant="secondary" disabled size="sm">
  <go-spinner></go-spinner>
  A processar
</go-button>

Badge

Também podes usar um spinner dentro de um <go-badge>.

A sincronizar A atualizar A processar 
<go-badge>
  <go-spinner size="xs"></go-spinner>
  A sincronizar
</go-badge>
<go-badge variant="secondary">
  <go-spinner size="xs"></go-spinner>
  A atualizar
</go-badge>
<go-badge variant="outline">
  <go-spinner size="xs"></go-spinner>
  A processar
</go-badge>

Input Group

O <go-input-group> pode conter spinners dentro de um addon. 

<go-input-group>
  <input slot="input" placeholder="Envia uma mensagem..." disabled />
  <span slot="addon-end">
    <go-spinner size="xs"></go-spinner>
  </span>
</go-input-group>

Estado vazio

Podes colocar um spinner dentro de um estado vazio para indicar que algo está em curso.

A processar o teu pedido

Aguarda enquanto processamos o teu pedido. Não atualizes a página.

Cancelar 
<go-card>
  <div class="flex flex-col items-center gap-3 p-6 text-center">
    <go-spinner size="lg"></go-spinner>
    <div class="text-base font-medium">A processar o teu pedido</div>
    <p class="text-sm text-muted-foreground">
      Aguarda enquanto processamos o teu pedido. Não atualizes a página.
    </p>
    <go-button variant="outline" size="sm">Cancelar</go-button>
  </div>
</go-card>

Item

Usa o spinner junto do conteúdo de um item para sinalizar um estado de carregamento.

A descarregar... 129 MB / 1000 MB
Cancelar 
<go-card>
  <div class="flex items-center gap-4 p-4">
    <go-spinner size="md"></go-spinner>
    <div class="flex flex-col">
      <span class="text-sm font-medium">A descarregar...</span>
      <span class="text-sm text-muted-foreground">129 MB / 1000 MB</span>
    </div>
    <go-button variant="outline" size="sm" class="ml-auto">Cancelar</go-button>
  </div>
</go-card>
