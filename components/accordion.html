Accordion

Um conjunto de cabeçalhos interativos empilhados verticalmente, em que cada um revela uma secção de conteúdo.

Sim. Cumpre o padrão de desenho WAI-ARIA.

<go-accordion type="single" collapsible>
  <section title="É acessível?" value="item-1">
    Sim. Cumpre o padrão de desenho WAI-ARIA.
  </section>
  <section title="Tem um estilo?" value="item-2">

</go-accordion>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-accordion> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section title="..." value="...">…</section> é um item do acordeão: title é o cabeçalho clicável e o conteúdo HTML interno é o painel. Usa type="single" (um item aberto de cada vez) ou type="multiple", e collapsible para permitir fechar todos. 

<go-accordion type="single" collapsible>
  <section title="É acessível?" value="item-1">
    Sim. Cumpre o padrão de desenho WAI-ARIA.
  </section>
</go-accordion>
Sim. Cumpre o padrão de desenho WAI-ARIA.

Múltiplo

Com type="multiple" vários painéis podem estar abertos ao mesmo tempo.

Os pedidos são processados em 24 horas úteis.
Aceitamos devoluções até 30 dias após a entrega.
Todos os produtos têm dois anos de garantia legal. 
<go-accordion type="multiple">
  <section title="Envio" value="env">
    Os pedidos são processados em 24 horas úteis.
  </section>
  <section title="Devoluções" value="dev">
    Aceitamos devoluções até 30 dias após a entrega.
  </section>
  <section title="Garantia" value="gar">

</go-accordion>

Item desativado

Adiciona o atributo disabled a uma <section> para a tornar não interativa.

Esta secção pode ser aberta normalmente.
Este conteúdo está bloqueado.
Esta secção também abre sem problema. 
<go-accordion type="single" collapsible>
  <section title="Disponível" value="a">
    Esta secção pode ser aberta normalmente.
  </section>
  <section title="Indisponível" value="b" disabled>
    Este conteúdo está bloqueado.
  </section>
  <section title="Disponível" value="c">
    Esta secção também abre sem problema.
  </section>
</go-accordion>
