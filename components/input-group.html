Input Group

Mostra informação ou ações adicionais junto a um campo de texto ou área de texto.

<go-input-group>
  <input data-slot="input-group-control" placeholder="Pesquisar..." />
  <div data-slot="input-group-addon" data-align="inline-start">
    <svg><!-- ícone lucide search --></svg>
  </div>
  <div data-slot="input-group-addon" data-align="inline-end">
    <button type="button">Pesquisar</button>
  </div>
</go-input-group>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-input-group> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <go-input-group> projeta o teu markup light-DOM intacto para dentro do contentor com a skin shadcn. O campo usa o contrato documentado data-slot="input-group-control" — o mesmo que a versão Vue aplica internamente — pelo que o estado de foco e os seletores has-[…] do contentor funcionam de forma idêntica. Os adornos são <div data-slot="input-group-addon"> posicionados com data-align (inline-start, inline-end, block-start, block-end). 

<go-input-group>
  <input data-slot="input-group-control" placeholder="Pesquisar..." />
  <div data-slot="input-group-addon" data-align="inline-start">
    <svg><!-- ícone --></svg>
  </div>
  <div data-slot="input-group-addon" data-align="inline-end">
    <button type="button">Pesquisar</button>
  </div>
</go-input-group>

Nota de arquitetura: a versão Vue do shadcn expõe sub-componentes (InputGroupInput, InputGroupAddon, InputGroupButton, InputGroupText, InputGroupTextarea) que pré-aplicam as classes. No Web Component compões com HTML nativo usando os mesmos atributos data-slot/data-align — a paridade 1:1 exata (ex.: variantes de InputGroupButton) exigiria sub-Custom-Elements com infraestrutura de registo partilhada.

Exemplos

Ícone

Coloca um ícone como adorno no início do campo, usando data-align="inline-start". 

<go-input-group>
  <input data-slot="input-group-control" type="email" placeholder="Email" />
  <div data-slot="input-group-addon" data-align="inline-start">
    <svg><!-- ícone lucide mail --></svg>
  </div>
</go-input-group>

Texto

Mostra texto informativo ao lado do campo — por exemplo um prefixo de URL ou um sufixo de domínio.

https://
@exemplo.com 
<go-input-group>
  <input data-slot="input-group-control" placeholder="exemplo.com" />
  <div data-slot="input-group-addon" data-align="inline-start">https://</div>
</go-input-group>

<go-input-group>
  <input data-slot="input-group-control" placeholder="utilizador" />
  <div data-slot="input-group-addon" data-align="inline-end">@exemplo.com</div>
</go-input-group>

Botão

Adiciona botões para executar ações dentro do grupo. O botão pode ficar à esquerda ou à direita do campo. 

<go-input-group>
  <input data-slot="input-group-control" placeholder="email@exemplo.com" />
  <div data-slot="input-group-addon" data-align="inline-end">
    <button type="button">Convidar</button>
  </div>
</go-input-group>

Área de texto

Os grupos também funcionam com áreas de texto. Usa data-align="block-end" para posicionar o adorno abaixo do conteúdo — o contentor empilha em coluna automaticamente. 

<go-input-group>
  <textarea data-slot="input-group-control" rows="3"
            placeholder="Escreve a tua mensagem..."></textarea>
  <div data-slot="input-group-addon" data-align="block-end">
    <button type="button">Enviar</button>
  </div>
</go-input-group>

Spinner

Mostra um indicador de carregamento como adorno enquanto o campo processa a ação. 

<go-input-group>
  <input data-slot="input-group-control" value="A verificar..." disabled />
  <div data-slot="input-group-addon" data-align="inline-end">
    <svg class="animate-spin"><!-- ícone lucide loader-circle --></svg>
  </div>
</go-input-group>

Exemplos que dependem de outros componentes

O shadcn-vue inclui ainda os exemplos Tooltip, Label, Dropdown, Button Group e Custom Input. Estes compõem o input-group com <go-tooltip>, <go-label>, <go-dropdown-menu> e um futuro <go-button-group>. A composição funciona, mas a paridade 1:1 exata com as variantes de InputGroupButton/InputGroupAddon exige sub-Custom-Elements partilhados — fica registado como decisão de arquitetura pendente (ver nota em Uso).
