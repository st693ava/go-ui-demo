Input Group

Mostra informação ou ações adicionais junto a um campo de texto ou área de texto.

Anterior Label Seguinte Scroll Area
⌕ 
<go-input-group>
  <span class="ig-addon" data-align="inline-start">⌕</span>
  <input class="ig-control" placeholder="Pesquisar..." />
  <span class="ig-addon" data-align="inline-end">
    <button type="button" class="ig-btn">Pesquisar</button>
  </span>
</go-input-group>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-input-group> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <go-input-group> projeta o teu markup light-DOM intacto para dentro do contentor com a skin shadcn — tu escreves o campo e os adornos diretamente como HTML. Coloca o campo de texto e, a seguir, os adornos (ícones, texto, botões) usando data-align="inline-start" ou inline-end para os posicionar. 

<go-input-group>
  <input class="ig-control" placeholder="Pesquisar..." />
  <span class="ig-addon" data-align="inline-start">⌕</span>
  <span class="ig-addon" data-align="inline-end">
    <button type="button" class="ig-btn">Pesquisar</button>
  </span>
</go-input-group>

Nota: ao contrário da versão Vue (que expõe InputGroupInput/InputGroupAddon), o Web Component não tem sub-elementos próprios — compõe o conteúdo com HTML nativo e classes utilitárias da página.

Exemplos

Ícone

Coloca um ícone como adorno no início do campo.

⌕ 
<go-input-group>
  <span class="ig-addon" data-align="inline-start">⌕</span>
  <input class="ig-control" placeholder="Pesquisar..." />
</go-input-group>

Texto

Mostra texto informativo ao lado do campo — por exemplo um prefixo de URL ou unidade.

https:// 
<go-input-group>
  <span class="ig-addon ig-text" data-align="inline-start">https://</span>
  <input class="ig-control" placeholder="exemplo.com" />
</go-input-group>

Botão

Adiciona botões para executar ações dentro do grupo. 

<go-input-group>
  <input class="ig-control" placeholder="email@exemplo.com" />
  <span class="ig-addon" data-align="inline-end">
    <button type="button" class="ig-btn">Convidar</button>
  </span>
</go-input-group>

Área de texto

Os grupos também funcionam com áreas de texto. Usa block-end para posicionar o adorno abaixo do conteúdo. 

<go-input-group>
  <textarea class="ig-control" rows="3"
            placeholder="Escreve a tua mensagem..."></textarea>
  <span class="ig-addon ig-addon-block" data-align="block-end">
    <button type="button" class="ig-btn ig-btn-fill">Enviar</button>
  </span>
</go-input-group>
