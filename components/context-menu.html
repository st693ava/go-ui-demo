Context Menu

Mostra um menu ao utilizador — como um conjunto de ações ou funções — acionado por um clique com o botão direito.

Anterior Dropdown Menu Seguinte Menubar
Clique com o botão direito aqui 
<go-context-menu>
  <div slot="trigger">Clique com o botão direito aqui</div>
  <option value="voltar" inset shortcut="⌘[">Voltar</option>
  <option value="avancar" inset shortcut="⌘]" disabled>Avançar</option>
  <option value="recarregar" inset shortcut="⌘R">Recarregar</option>
  <section title="Mais ferramentas">
    <option value="guardar-pagina" shortcut="⇧⌘S">Guardar página…</option>
    <option value="criar-atalho">Criar atalho…</option>
    <option value="nomear-janela">Nomear janela…</option>
    <option value="dev-tools">Ferramentas de programador</option>
    <option value="eliminar">Eliminar</option>
  </section>
  <option type="separator"></option>
  <option type="checkbox" value="favoritos" checked>Mostrar favoritos</option>
  <option type="checkbox" value="urls">Mostrar URLs completos</option>
  <option type="separator"></option>
  <option type="label" inset>Pessoas</option>
  <option type="radio" name="pessoa" value="pedro" checked>Pedro Duarte</option>
  <option type="radio" name="pessoa" value="colm">Colm Tuite</option>
</go-context-menu>

bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-context-menu> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo de <div slot="trigger"> é a área sensível ao clique-direito. Cada <option value="x">Etiqueta</option> é um item; ao selecionar, o elemento dispara um evento select com detail.value. Atributos declarativos opcionais: shortcut, disabled, type="label|separator", type="checkbox" checked, type="radio" name="g" (grupo de opção) e uma <section title="..."> aninhada para submenu. 

<go-context-menu>
  <div slot="trigger">Clique com o botão direito</div>
  <option value="recarregar" shortcut="⌘R">Recarregar</option>
  <option type="separator"></option>
  <option type="checkbox" value="favoritos" checked>Favoritos</option>
</go-context-menu>
document
  .querySelector('go-context-menu')
  .addEventListener('select', (e) => {
    console.log(e.detail.value) // 'perfil' | 'faturacao' | ...
  })

Exemplos

Menu de ações

As ações típicas de uma conta, expostas via clique-direito sobre uma área da interface.

Área de trabalho 
<go-context-menu>
  <div slot="trigger">Área de trabalho</div>
  <option value="perfil">Perfil</option>
  <option value="faturacao">Faturação</option>
  <option value="equipa">Equipa</option>
  <option value="subscricao">Subscrição</option>
</go-context-menu>

Item desativado

Marca um item com o atributo disabled para o tornar não selecionável.

Item da galeria 
<go-context-menu>
  <div slot="trigger">Item da galeria</div>
  <option value="abrir">Abrir</option>
  <option value="renomear">Renomear</option>
  <option value="bloquear" disabled>Bloquear</option>
  <option value="eliminar">Eliminar</option>
</go-context-menu>

Verificação e opção

Itens type="checkbox" alternam um estado visível; itens type="radio" com o mesmo name formam um grupo de seleção exclusiva.

Vista da grelha
 
<go-context-menu>
  <div slot="trigger">Vista da grelha</div>
  <option type="label">Apresentação</option>
  <option type="checkbox" value="grelha" checked>Mostrar grelha</option>
  <option type="checkbox" value="reguas">Mostrar réguas</option>
  <option type="separator"></option>
  <option type="label">Ordenar por</option>
  <option type="radio" name="ordem" value="nome" checked>Nome</option>
  <option type="radio" name="ordem" value="data">Data</option>
  <option type="radio" name="ordem" value="tamanho">Tamanho</option>
</go-context-menu>

Sobre um cartão

O slot trigger aceita qualquer HTML — aqui um cartão inteiro torna-se a área de clique-direito, ação comum em listas e grelhas de conteúdo.

Relatório Q2 Atualizado há 3 dias 
<go-context-menu>
  <div slot="trigger">
    <strong>Relatório Q2</strong>
    <span>Atualizado há 3 dias</span>
  </div>
  <option value="abrir">Abrir</option>
  <option value="partilhar">Partilhar</option>
  <option value="duplicar">Duplicar</option>
  <option value="arquivar">Arquivar</option>
</go-context-menu>
