Label

Renderiza uma etiqueta acessível associada a controlos de formulário.

Anterior Button Seguinte Input Group
Aceito os termos e condições 
<go-checkbox id="terms"></go-checkbox>
<go-label for="terms">Aceito os termos e condições</go-label>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-label> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Usa o atributo for para apontar para o id do controlo associado. Ao clicar na etiqueta o controlo recebe o foco. 

<go-label for="email">O teu endereço de email</go-label>
O teu endereço de email 
<go-label for="email">O teu endereço de email</go-label>

Exemplos

Com checkbox

Associa a etiqueta a um <go-checkbox> pelo for; clicar no texto alterna o estado.

Aceito os termos e condições 
<go-checkbox id="terms"></go-checkbox>
<go-label for="terms">Aceito os termos e condições</go-label>

Com campo de texto

Empilha a etiqueta sobre um <go-input> para um campo de formulário acessível.

Email 
<go-label for="email">Email</go-label>
<go-input id="email" type="email" placeholder="email@exemplo.com"></go-input>

Estado desativado

Quando o controlo associado está desativado, a etiqueta acompanha visualmente o estado via o seletor de grupo da skin.

Opção indisponível 
<go-checkbox id="terms" disabled></go-checkbox>
<go-label for="terms">Opção indisponível</go-label>
