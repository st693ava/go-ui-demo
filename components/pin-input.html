Pin Input

Campo de PIN acessível com suporte a copiar-colar, ideal para códigos de verificação (OTP).

Anterior Number Field Seguinte Tags Input 
<go-pin-input name="otp" length="6"></go-pin-input>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-pin-input> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O atributo length define o número de casas (default 6). O name liga-o a um formulário (FACE), submetendo o código concatenado; required bloqueia o submit enquanto o código estiver incompleto. O componente emite change a cada dígito e complete quando todas as casas estão preenchidas. Nota: a montante o shadcn-vue marcou o Pin Input como descontinuado a favor do Input OTP; o <go-pin-input> mantém-no como componente FACE estável e os exemplos abaixo são próprios do go-ui. 

<go-pin-input name="otp" length="6"></go-pin-input>
<go-pin-input name="otp" length="6"></go-pin-input>

Exemplos

Default

O exemplo base: seis casas para um código de verificação. 

<go-pin-input name="otp" length="6"></go-pin-input>

Comprimento

Ajusta o número de casas com length — aqui um PIN de 4 dígitos. 

<go-pin-input name="pin" length="4"></go-pin-input>

Disabled

O atributo disabled bloqueia a introdução. 

<go-pin-input name="otp" length="6" disabled></go-pin-input>

Formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Com required, o submit é bloqueado enquanto o código não estiver completo.

Código de verificação Confirmar 
<form>
  <go-label>Código de verificação</go-label>
  <go-pin-input name="code" length="6" required></go-pin-input>
  <go-button type="submit">Confirmar</go-button>
</form>
