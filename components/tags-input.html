Tags Input

O campo de tags mostra etiquetas dentro de um input, seguidas de uma zona de texto para adicionar novas.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-tags-input> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Escreve no campo e prime Enter para adicionar uma tag; cada tag tem um botão para a remover. O atributo value define as tags iniciais (separadas por vírgula, ou pelo delimiter que escolheres) e placeholder o texto do input. O name liga-o a um formulário (FACE) — cada tag submete-se como uma entrada própria, em paridade com <select multiple>. O componente emite change com o array de tags. 

<go-tags-input name="fruits" value="Maçã,Banana" placeholder="Frutas..."></go-tags-input>
<go-tags-input name="fruits" value="Maçã,Banana" placeholder="Frutas..."></go-tags-input>

Exemplos

Default

O exemplo base: arranca com duas tags e um campo para adicionar mais. Escreve e prime Enter para adicionar; clica no × para remover. 

<go-tags-input name="fruits" value="Maçã,Banana" placeholder="Frutas..."></go-tags-input>

Disabled

O atributo disabled bloqueia a adição e remoção de tags. 

<go-tags-input name="fruits" placeholder="Frutas..." disabled></go-tags-input>

Estado inicial

Define as tags iniciais com o atributo value (lista separada por vírgula). Para um separador diferente — útil quando os valores contêm vírgulas — usa delimiter. 

<go-tags-input
  name="seeded"
  value="Nuxt;Remix;Astro"
  delimiter=";"
  placeholder="Frameworks..."
></go-tags-input>

Com Listbox

O exemplo "Tags with Listbox" do shadcn-vue compõe um TagsInput com um Popover e um ListboxRoot do Reka para autocompletar. Esta composição multi-componente com estado partilhado não é exprimível como Web Component declarativo simples — pelo que não está incluída aqui, para não apresentar um exemplo falso. Adiciona tags livremente escrevendo no campo e premindo Enter.

Formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Com required, o submit é bloqueado enquanto não houver pelo menos uma tag. Cada tag é submetida como entrada repetida do name.

Etiquetas Submeter 
<form>
  <go-label>Etiquetas</go-label>
  <go-tags-input name="tags" required placeholder="Adicionar..."></go-tags-input>
  <go-button type="submit">Submeter</go-button>
</form>
