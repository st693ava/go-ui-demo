Range Calendar

Apresenta uma vista de calendário pensada para selecionar intervalos de datas.

<go-range-calendar
  value="2026-05-18/2026-05-25"
  number-of-months="2"
></go-range-calendar>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-range-calendar> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <go-range-calendar> é autónomo (sem trigger nem popover). O atributo value define o intervalo inicial no formato "AAAA-MM-DD/AAAA-MM-DD". Ao completar uma nova seleção, emite o evento change com detail: { start, end } em ISO. 

<go-range-calendar></go-range-calendar>
<go-range-calendar></go-range-calendar>

Exemplos

Intervalo predefinido

Com dois meses visíveis e os dias fora do mês atual ocultos (number-of-months="2"), arrancando com um intervalo de sete dias já selecionado. 

<go-range-calendar
  value="2026-05-18/2026-05-25"
  number-of-months="2"
></go-range-calendar>

Um único mês

Define number-of-months="1" para mostrar apenas um mês de cada vez. 

<go-range-calendar
  number-of-months="1"
></go-range-calendar>

Localização

O atributo locale controla os nomes dos meses, os dias da semana e a ordem de início da semana. O valor por defeito é pt. 

<go-range-calendar
  locale="en"
  value="2026-05-18/2026-05-25"
></go-range-calendar>

Reagir ao evento change

Escuta o evento change para obter o intervalo selecionado em ISO assim que o utilizador escolhe um início e um fim. 

document
  .querySelector('go-range-calendar')
  .addEventListener('change', (e) => {
    const { start, end } = e.detail
    console.log(start, '→', end)
  })
