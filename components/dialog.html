Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-dialog> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'

Uso

O <span slot="trigger"> é o botão que abre o diálogo. O conteúdo é teleportado para o <body> e organizado por regiões nomeadas: slot="title", slot="description", slot="content" e slot="footer". 

<go-dialog>
  <span slot="trigger">Abrir</span>
  <div slot="title">Tens a certeza?</div>
  <div slot="description">
    Esta ação não pode ser anulada. Vai apagar a tua conta
    permanentemente e remover os teus dados dos nossos servidores.
  </div>
</go-dialog>

Exemplos

Botão de fecho personalizado

Coloca a ação de fecho no slot="footer" — por exemplo, um botão "Fechar" explícito além do X por defeito.

Dialog com formulário

O slot="content" aceita qualquer markup, incluindo um formulário completo. O conteúdo é author-controlled.

Modal responsivo (Dialog & Drawer)

O shadcn-vue propõe um Drawer em viewports estreitos e um Dialog nos restantes. Em go-ui ambos são componentes reais com a mesma API de slots (trigger/title/description/content/footer), por isso basta renderizar os dois e deixar uma media query local mostrar o adequado. Em ecrã largo abre o <go-dialog>; abaixo de 640 px o <go-drawer> — redimensiona a janela para ver a troca.

<!-- Mesmo conteúdo em ambos; a media query mostra um deles -->
<div class="modal-responsive">
  <go-dialog class="wide">
    <span slot="trigger">Partilhar ligação</span>
    <div slot="title">Partilhar ligação</div>
    <div slot="content"><input readonly value="https://go-ui.dev/docs/installation" /></div>
    <div slot="footer"><button>Fechar</button></div>
  </go-dialog>
  <go-drawer class="narrow">
    <span slot="trigger">Partilhar ligação</span>
    <div slot="title">Partilhar ligação</div>
    <div slot="content"><input readonly value="https://go-ui.dev/docs/installation" /></div>
    <div slot="footer"><button>Fechar</button></div>
  </go-drawer>
</div>

<style>

  }
</style>
