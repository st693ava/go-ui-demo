Estrutura

O <go-sidebar> é data-driven. Os itens declaram-se com <section title="Grupo"> contendo <option value="/url">Item</option>. As regiões slot="header", slot="footer" e slot="content" preenchem topo, rodapé e área principal. Clicar num item dispara o evento navigate com detail.value.

Há dois modos: mode="shell" (default) — app-shell completo com cabeçalho, área de conteúdo e barra position:fixed; e mode="nav" — apenas a coluna de navegação reutilizável (itens são <a href> nativos), ideal como sidebar de página. O atributo active realça o item cujo value coincide.

Uso

<go-sidebar mode="nav" active="/dashboard">
  <section title="Plataforma">
    <option value="/dashboard">Dashboard</option>
    <option value="/projetos">Projetos</option>
  </section>
</go-sidebar>

Exemplos

Modo navegação

Com mode="nav" obténs só a coluna de navegação, sem shell nem position:fixed — exatamente o que esta página usa como barra lateral esquerda. Os itens são âncoras nativas e active realça o atual. 

<go-sidebar mode="nav" active="/projetos">
  <section title="Plataforma">
    <option value="/dashboard">Dashboard</option>
    <option value="/projetos">Projetos</option>
    <option value="/equipa">Equipa</option>
  </section>
  <section title="Conta">
    <option value="/definicoes">Definições</option>
    <option value="/sair" disabled>Sair</option>
  </section>
</go-sidebar>

Com cabeçalho e rodapé

As regiões slot="header" e slot="footer" ficam fixas no topo e fundo da barra (marca, perfil do utilizador, etc.).

jaime@acme.pt

Lado direito

Usa side="right" para ancorar a barra à direita do shell.

Conteúdo

Barra lateral ancorada à direita.

 
<go-sidebar mode="shell" side="right">
  <section title="Painel">
    <option value="/atividade">Atividade</option>
    <option value="/notificacoes">Notificações</option>
  </section>
  <div slot="content">

  </div>
</go-sidebar>

Variante

Usa variant para mudar a aparência da barra: sidebar (default), floating ou inset.

Recolhível

Usa collapsible para definir como a barra recolhe: offcanvas (default), icon ou none. Clica no botão do cabeçalho do shell para alternar.
