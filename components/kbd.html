Kbd

Mostra entrada textual do utilizador a partir do teclado.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-kbd> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <go-kbd>Tecla</go-kbd> representa uma tecla do teclado. O conteúdo projetado pode ser texto (Ctrl, Esc) ou um símbolo (⌘, ⏎). 

<go-kbd>Ctrl</go-kbd>
Ctrl 
<go-kbd>Ctrl</go-kbd>

Exemplos

Grupo

Usa o atributo group para agrupar teclas. O próprio <go-kbd group> torna-se o contentor e projeta os <go-kbd> internos lado a lado.

Usa Ctrl + B Ctrl + K para abrir a paleta de comandos 

<p>
  Usa
  <go-kbd group>
    <go-kbd>Ctrl + B</go-kbd>
    <go-kbd>Ctrl + K</go-kbd>
  </go-kbd>
  para abrir a paleta de comandos
</p>

Botão

Usa o <go-kbd> dentro de um <go-button> para mostrar a tecla de atalho dentro do botão.

Aceitar ⏎ Cancelar Esc 
<go-button variant="outline" size="sm">
  Aceitar <go-kbd>⏎</go-kbd>
</go-button>
<go-button variant="outline" size="sm">
  Cancelar <go-kbd>Esc</go-kbd>
</go-button>

Tooltip

Podes usar o <go-kbd> dentro de um <go-tooltip> para mostrar a tecla de atalho na dica.

Guardar
Guardar alterações S
Imprimir
Imprimir documento Ctrl P 
<go-tooltip>
  <go-button slot="trigger" variant="outline" size="sm">Guardar</go-button>
  <div slot="content">Guardar alterações <go-kbd>S</go-kbd></div>
</go-tooltip>

<go-tooltip>
  <go-button slot="trigger" variant="outline" size="sm">Imprimir</go-button>
  <div slot="content">
    Imprimir documento
    <go-kbd group>
      <go-kbd>Ctrl</go-kbd>
      <go-kbd>P</go-kbd>
    </go-kbd>
  </div>
</go-tooltip>

Input Group

Podes usar o <go-kbd> dentro de um <go-input-group> para mostrar a tecla de atalho dentro do campo.

⌘ K 
<go-input-group>
  <input data-slot="input-group-control" placeholder="Pesquisar..." />
  <div data-slot="input-group-addon" data-align="inline-start">
    <svg><!-- ícone lucide search --></svg>
  </div>
  <div data-slot="input-group-addon" data-align="inline-end">
    <go-kbd>⌘</go-kbd>
    <go-kbd>K</go-kbd>
  </div>
</go-input-group>
