Toggle Group

Um conjunto de botões de dois estados que podem ser ligados ou desligados.

Anterior Toggle Seguinte Toaster 
<go-toggle-group type="multiple">
  <option value="bold">B</option>
  <option value="italic">I</option>
  <option value="underline">U</option>
</go-toggle-group>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-toggle-group> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="..."> é um item. Usa type="single" ou type="multiple"; o evento change traz detail.value (string em single, array em multiple). value define a seleção inicial (lista separada por vírgulas em multiple). 

<go-toggle-group type="multiple">
  <option value="a">A</option>
  <option value="b">B</option>
  <option value="c">C</option>
</go-toggle-group>

Exemplos

Default

Grupo de seleção múltipla, variante por defeito.

<go-toggle-group type="multiple">
  <option value="bold">B</option>
  <option value="italic">I</option>
  <option value="underline">U</option>
</go-toggle-group>

Contorno

Usa variant="outline" para itens com contorno. 

<go-toggle-group type="multiple" variant="outline">
  <option value="bold">B</option>
  <option value="italic">I</option>
  <option value="underline">U</option>
</go-toggle-group>

Single

Com type="single" apenas um item pode estar ativo de cada vez. 

<go-toggle-group type="single" value="center">
  <option value="left">Esquerda</option>
  <option value="center">Centro</option>
  <option value="right">Direita</option>
</go-toggle-group>

Pequeno

Usa size="sm" para um grupo pequeno.

<go-toggle-group type="multiple" size="sm">
  <option value="bold">B</option>
  <option value="italic">I</option>
  <option value="underline">U</option>
</go-toggle-group>

Grande

Usa size="lg" para um grupo grande.

<go-toggle-group type="multiple" size="lg">
  <option value="bold">B</option>
  <option value="italic">I</option>
  <option value="underline">U</option>
</go-toggle-group>

Desativado

Marca um item com disabled para o tornar não interativo. 

<go-toggle-group type="multiple">
  <option value="bold">B</option>
  <option value="italic" disabled>I</option>
  <option value="underline">U</option>
</go-toggle-group>
