Combobox

Campo de autocompletar e paleta de comandos com uma lista de sugestões.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

O Combobox é uma composição de <go-popover> e <go-command>. Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-combobox> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="valor">Etiqueta</option> é uma sugestão. Ao escolher uma opção, o popover fecha e o componente dispara um evento change com detail.value. O campo de pesquisa filtra as opções em tempo real. 

<go-combobox
  placeholder="Selecione a framework..."
  search-placeholder="Pesquisar framework..."
  empty-text="Sem frameworks."
>
  <option value="next.js">Next.js</option>
  <option value="sveltekit">SvelteKit</option>
  <option value="nuxt.js">Nuxt.js</option>
  <option value="remix">Remix</option>
  <option value="astro">Astro</option>
</go-combobox>
document
  .querySelector('go-combobox')
  .addEventListener('change', (e) => {
    console.log(e.detail.value) // 'next.js'
  })

Exemplos

Combobox

Um combobox com uma lista de frameworks — réplica do exemplo ComboboxDemo do shadcn-vue. 

<go-combobox
  placeholder="Selecione a framework..."
  search-placeholder="Pesquisar framework..."
  empty-text="Nenhuma framework encontrada."
>
  <option value="next.js">Next.js</option>
  <option value="sveltekit">SvelteKit</option>
  <option value="nuxt.js">Nuxt.js</option>
  <option value="remix">Remix</option>
  <option value="astro">Astro</option>
</go-combobox>

Valor inicial

Usa o atributo value para pré-selecionar uma opção. O trigger mostra a etiqueta correspondente desde o início. 

<go-combobox value="astro" placeholder="Selecione...">
  <option value="next.js">Next.js</option>
  <option value="sveltekit">SvelteKit</option>
  <option value="nuxt.js">Nuxt.js</option>
  <option value="remix">Remix</option>
  <option value="astro">Astro</option>
</go-combobox>

Selecionar estado

O mesmo padrão serve como seletor de estado num popover compacto. 

<go-combobox
  placeholder="Definir estado"
  search-placeholder="Filtrar estado..."
  empty-text="Sem estados."
>
  <option value="backlog">Em espera</option>
  <option value="todo">Por fazer</option>
  <option value="in-progress">Em curso</option>
  <option value="done">Concluído</option>
  <option value="canceled">Cancelado</option>
</go-combobox>

Opções desativadas

Adiciona o atributo disabled a uma <option> para a tornar não selecionável. 

<go-combobox placeholder="Selecione o plano...">
  <option value="free">Gratuito</option>
  <option value="pro">Pro</option>
  <option value="team" disabled>Equipa (em breve)</option>
  <option value="enterprise">Empresa</option>
</go-combobox>
