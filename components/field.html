Field

Combina etiquetas, controlos e texto de ajuda para compor campos de formulário acessíveis e grupos de campos.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-field> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Uma única convenção declarativa cobre toda a família. O atributo as escolhe o papel: field (default, um campo único), set (<fieldset> semântico com legend), group (empilha campos) e separator (divisor). A etiqueta, descrição, erro e legenda são atributos ou slots nomeados de texto estático (label/description/error/legend); o controlo interativo (go-input, go-checkbox, etc.) vai no slot por defeito. 

<go-field label="Etiqueta" for="input-id" description="Texto de ajuda opcional.">
  <go-input id="input-id" name="campo"></go-input>
</go-field>
<go-field label="Etiqueta" for="input-id" description="Texto de ajuda opcional.">
  <go-input id="input-id" name="campo"></go-input>
</go-field>

Exemplos

Input

Campos de texto empilhados dentro de um as="group", cada um com etiqueta e descrição. 

<go-field as="group">
  <go-field
    label="Nome de utilizador"
    for="username"
    description="Escolhe um nome de utilizador único para a tua conta."
  >
    <go-input id="username" name="username" type="text" placeholder="Max Leiter"></go-input>
  </go-field>
  <go-field
    label="Palavra-passe"
    for="password"
    description="Tem de ter pelo menos 8 caracteres."
  >
    <go-input id="password" name="password" type="password" placeholder="********"></go-input>
  </go-field>
</go-field>

Textarea

Combina uma go-textarea com etiqueta e texto de ajuda. 

<go-field
  label="Comentários"
  for="feedback"
  description="Partilha a tua opinião sobre o nosso serviço."
>
  <go-textarea id="feedback" name="feedback" placeholder="A tua opinião ajuda-nos a melhorar..."></go-textarea>
</go-field>

Select

Um go-select envolvido por um campo com etiqueta e descrição. 

<go-field
  label="Departamento"
  description="Seleciona o teu departamento ou área de trabalho."
>
  <go-select name="department" placeholder="Escolhe o departamento">
    <option value="engineering">Engenharia</option>
    <option value="design">Design</option>
    <option value="marketing">Marketing</option>
    <option value="sales">Vendas</option>
    <option value="support">Apoio ao cliente</option>
  </go-select>
</go-field>

Slider

Usa title para o título do campo e go-slider como controlo. 

<go-field
  title="Intervalo de preço"
  description="Define o teu orçamento ($200 - $800)."
>
  <go-slider name="price" min="0" max="1000" step="10" value="200" aria-label="Intervalo de preço"></go-slider>
</go-field>

Fieldset

as="set" renderiza um <fieldset> semântico com legend e descrição, agrupando campos relacionados. 

<go-field
  as="set"
  legend="Informação de morada"
  description="Precisamos da tua morada para entregar a encomenda."
>
  <go-field as="group">
    <go-field label="Rua" for="street">
      <go-input id="street" name="street" placeholder="Rua Principal 123"></go-input>
    </go-field>
    <go-field label="Cidade" for="city">
      <go-input id="city" name="city" placeholder="Lisboa"></go-input>
    </go-field>
  </go-field>
</go-field>

Checkbox

Cada go-checkbox traz a sua própria etiqueta; agrupa-os num as="set" com legenda e descrição.

Radio

Combina um go-radio-group com legenda e descrição num as="set". 

<go-field
  as="set"
  legend="Plano de subscrição"
  legend-variant="label"
  description="Os planos anuais e vitalícios oferecem poupanças significativas."
>
  <go-radio-group name="plan" value="monthly">
    <option value="monthly">Mensal (9,99 €/mês)</option>
    <option value="yearly">Anual (99,99 €/ano)</option>
    <option value="lifetime">Vitalício (299,99 €)</option>
  </go-radio-group>
</go-field>

Switch

Campo horizontal com descrição no slot content e o go-switch ao lado.

Autenticação multifator Ativa a autenticação multifator. Se não tiveres um dispositivo de dois fatores, podes usar um código único enviado para o teu e-mail. 
<go-field orientation="horizontal">
  <go-switch name="2fa">Autenticação multifator</go-switch>
  <span slot="description">Ativa a autenticação multifator. Podes usar um código único enviado para o teu e-mail.</span>
</go-field>

Choice Card

Compõe campos horizontais com go-radio-group para criar grupos de campos selecionáveis em forma de cartão. 

<go-field
  as="set"
  legend="Ambiente de computação"
  legend-variant="label"
  description="Seleciona o ambiente de computação para o teu cluster."
>
  <go-radio-group name="compute" value="kubernetes">
    <option value="kubernetes">Kubernetes — Executa cargas GPU num cluster K8s</option>
    <option value="vm">Máquina virtual — Acede a um cluster VM para cargas GPU</option>
  </go-radio-group>
</go-field>

Field Group

Empilha campos com as="group" e usa as="separator" para os dividir.

Notificações push Recebe notificação quando as tuas tarefas têm atualizações. Gerir tarefas Notificações push Notificações por e-mail 
<go-field as="group">
  <go-field as="set" legend="Respostas" legend-variant="label"
    description="Recebe notificação quando uma resposta demora.">
    <go-field as="group">
      <go-field orientation="horizontal">
        <go-checkbox name="push" checked disabled>Notificações push</go-checkbox>
      </go-field>
    </go-field>
  </go-field>
  <go-field as="separator"></go-field>
  <go-field as="set" legend="Tarefas" legend-variant="label">
    <span slot="description">Recebe notificação quando as tuas tarefas têm atualizações.</span>
    <go-field as="group">
      <go-field orientation="horizontal">
        <go-checkbox name="push-tasks">Notificações push</go-checkbox>
      </go-field>
    </go-field>
  </go-field>
</go-field>

Layout responsivo

Com orientation="responsive" o campo empilha em ecrãs estreitos e alinha label e controlo lado a lado em ecrãs largos, dentro de um as="group".

NomeIndica o teu nome completo para identificação MensagemEscreve a tua mensagem aqui. Mantém-na curta, idealmente abaixo de 100 caracteres. 
<go-field as="set" legend="Perfil" description="Preenche a informação do teu perfil.">
  <go-field as="separator"></go-field>
  <go-field as="group">
    <go-field orientation="responsive">
      <span slot="content">
        <span data-slot="field-label">Nome</span>
        <span>Indica o teu nome completo para identificação</span>
      </span>
      <go-input name="name" placeholder="Evil Rabbit"></go-input>
    </go-field>
    <go-field as="separator"></go-field>
    <go-field orientation="responsive">
      <span slot="content">
        <span data-slot="field-label">Mensagem</span>
        <span>Escreve a tua mensagem aqui.</span>
      </span>
      <go-textarea name="message" placeholder="Olá, mundo!"></go-textarea>
    </go-field>
  </go-field>
</go-field>

Validação e erros

Adiciona invalid ao go-field para mudar o bloco para estado de erro e usa error para a mensagem de validação, renderizada a seguir ao controlo. 

<go-field
  invalid
  label="E-mail"
  for="email"
  error="Introduz um endereço de e-mail válido."
>
  <go-input id="email" name="email" type="email" aria-invalid="true"></go-input>
</go-field>
