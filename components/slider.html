Slider

Um campo em que o utilizador seleciona um valor dentro de um intervalo dado.

Anterior Textarea Seguinte Radio Group 
<go-slider name="volume" min="0" max="100" step="1" value="50"></go-slider>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-slider> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define o intervalo com min, max e step, e o valor inicial com value. O name liga o valor (lista separada por vírgulas) ao <form> nativo via ElementInternals (FACE). 

<go-slider name="volume" min="0" max="100" step="1" value="50"></go-slider>
<go-slider name="volume" min="0" max="100" step="1" value="50"></go-slider>

Exemplos

Por defeito

Um slider de valor único com intervalo 0–100 e valor inicial 50. 

<go-slider name="value" min="0" max="100" step="1" value="50"></go-slider>

Passo personalizado

Ajusta step para incrementos maiores — aqui de 10 em 10. 

<go-slider name="step10" min="0" max="100" step="10" value="40"></go-slider>

Desativado

O atributo disabled impede a interação e remove o valor da submissão. 

<go-slider name="value" min="0" max="100" step="1" value="50" disabled></go-slider>

Com etiqueta

Compõe <go-label> com <go-slider> ao nível da página para um campo etiquetado.

Brilho 
<go-label for="brightness">Brilho</go-label>
<go-slider name="brightness" min="0" max="100" step="1" value="65"></go-slider>

Num formulário

Como FACE form-input, a <go-slider> participa na submissão do <form> nativo pelo seu name — o valor é submetido como lista separada por vírgulas.

Qualidade
Submeter {} 
<form>
  <go-label for="quality">Qualidade</go-label>
  <go-slider name="quality" min="0" max="100" step="5" value="75"></go-slider>
  <go-button type="submit">Submeter</go-button>
</form>
