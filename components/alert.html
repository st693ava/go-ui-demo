Alert

Mostra um aviso destacado para chamar a atenção do utilizador.

Anterior Card Seguinte Badge
Sucesso! As tuas alterações foram guardadas
Este é um aviso com ícone, título e descrição. 
<go-alert>
  <div slot="title">Sucesso! As tuas alterações foram guardadas</div>
  <div slot="description">Este é um aviso com ícone, título e descrição.</div>
</go-alert>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-alert> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Coloca o título em slot="title" e o corpo em slot="description". Sem slot="description" o conteúdo por defeito do elemento passa a ser a descrição. O atributo variant aceita default ou destructive. 

<go-alert>
  <div slot="title">Atenção!</div>
  <div slot="description">
    Podes adicionar componentes à tua app pela CLI.
  </div>
</go-alert>

Exemplos

Aviso com ícone, título e descrição

Coloca o ícone no conteúdo por defeito (antes dos slots) — a skin posiciona qualquer <svg> na coluna do ícone.

Sucesso! As tuas alterações foram guardadas
Este é um aviso com ícone, título e descrição. 
<go-alert>
  <svg ...><!-- ícone de confirmação --></svg>
  <div slot="title">Sucesso! As tuas alterações foram guardadas</div>
  <div slot="description">Este é um aviso com ícone, título e descrição.</div>
</go-alert>

Apenas título e ícone

Sem slot="description" e sem conteúdo de texto por defeito, o aviso fica com uma única linha de título.

Este aviso tem título e ícone. Sem descrição. 
<go-alert>
  <svg ...><!-- ícone --></svg>
  <div slot="title">Este aviso tem título e ícone. Sem descrição.</div>
</go-alert>

Destrutivo

Com variant="destructive" o aviso passa a tom de erro. A descrição pode conter HTML arbitrário (parágrafos, listas).

Não foi possível processar o pagamento.

Verifica os dados de faturação e tenta novamente.

  • Confirma os dados do cartão
  • Garante saldo suficiente
  • Verifica a morada de faturação
 
<go-alert variant="destructive">
  <svg ...><!-- ícone de erro --></svg>
  <div slot="title">Não foi possível processar o pagamento.</div>
  <div slot="description">
    <p>Verifica os dados de faturação e tenta novamente.</p>
    <ul>
      <li>Confirma os dados do cartão</li>
      <li>Garante saldo suficiente</li>
      <li>Verifica a morada de faturação</li>
    </ul>
  </div>
</go-alert>
