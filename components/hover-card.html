Hover Card

Para utilizadores com visão pré-visualizarem o conteúdo por trás de um link.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-hover-card> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O slot="trigger" é o elemento que, ao ser apontado, revela o cartão; o conteúdo vem do slot="content" (ou de qualquer markup sem slot, como defaultHtml). 

<go-hover-card>
  <a slot="trigger" href="#">Apontar</a>
  <div slot="content">A framework Vue — criada e mantida pelo Evan You.</div>
</go-hover-card>
