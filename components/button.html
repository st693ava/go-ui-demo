Button

Mostra um botão ou um componente com aparência de botão.

Anterior Skeleton Seguinte Label
Button 
<go-button variant="outline">Button</go-button>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-button> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo do botão é o texto (ou markup) entre as tags. Usa o atributo variant para o estilo e size para a dimensão. Liga listeners diretamente ao elemento <go-button>. 

<go-button variant="outline">Button</go-button>
Button 
<go-button variant="outline">Button</go-button>

Exemplos

Default

O botão por defeito, com um botão de ícone ao lado.

Button ↑ 
<go-button variant="outline">Button</go-button>
<go-button variant="outline" size="icon" aria-label="Submeter">
  ↑
</go-button>

Secondary

Variante secundária para ações de menor ênfase.

Secondary 
<go-button variant="secondary">Secondary</go-button>

Outline

Variante com contorno e fundo transparente.

Outline 
<go-button variant="outline">Outline</go-button>

Ghost

Variante sem fundo nem contorno até ao hover.

Ghost 
<go-button variant="ghost">Ghost</go-button>

Destructive

Variante para ações destrutivas (apagar, remover).

Destructive 
<go-button variant="destructive">Destructive</go-button>

Link

Variante com aparência de hiperligação.

Link 
<go-button variant="link">Link</go-button>

Icon

Usa size="icon" para um botão quadrado só com ícone.

⟳ 
<go-button variant="outline" size="icon" aria-label="Atualizar">
  ⟳
</go-button>

With Icon

O espaçamento entre o ícone e o texto é ajustado automaticamente em função do size. Não precisas de margens no ícone.

⎇ Novo ramo 
<go-button variant="outline" size="sm">
  ⎇ Novo ramo
</go-button>

Spinner

Estado de carregamento — desativa o botão e mostra um indicador enquanto a ação processa.

Submeter 
<go-button variant="outline" size="sm" disabled>
  <span class="spinner"></span> Submeter
</go-button>

Link (asChild)

Para uma hiperligação com aparência de botão, coloca um <a> dentro do <go-button>: o conteúdo light-DOM é projetado intacto, pelo que a âncora navega nativamente mantendo a skin.

Entrar 
<go-button variant="outline">
  <a href="/login">Entrar</a>
</go-button>
