Native Select

Um <select> nativo do browser estilizado, com integração consistente no sistema de design.

<go-native-select aria-label="Escolha uma fruta">
  <option value="">Escolha uma fruta</option>
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
  <option value="blueberry">Mirtilo</option>
  <option value="grapes" disabled>Uvas</option>
  <option value="pineapple">Ananás</option>
</go-native-select>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-native-select> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Declara cada <option value="…">Etiqueta</option> no light-DOM. O <go-native-select> projeta-os para um <select> nativo estilizado e, como Custom Element Form-Associated, submete o valor em qualquer <form> através do atributo name. 

<go-native-select name="fruit">
  <option value="">Escolha uma fruta</option>
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
</go-native-select>
<go-native-select>
  <option value="">Escolha uma fruta</option>
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
</go-native-select>

Exemplos

Com grupos

Organiza as opções com <optgroup label="…"> para uma melhor categorização. 

<go-native-select>
  <option value="">Escolha um alimento</option>
  <optgroup label="Frutas">
    <option value="apple">Maçã</option>
    <option value="banana">Banana</option>
    <option value="blueberry">Mirtilo</option>
  </optgroup>
  <optgroup label="Legumes">
    <option value="carrot">Cenoura</option>
    <option value="broccoli">Brócolos</option>
    <option value="spinach">Espinafres</option>
  </optgroup>
</go-native-select>

Estado desativado

Desativa opções individuais ou o componente inteiro com o atributo disabled. 

<go-native-select disabled>
  <option value="">Escolha uma fruta</option>
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
</go-native-select>

Estado inválido

Mostra erros de validação com o atributo aria-invalid e o estilo de erro associado. 

<go-native-select aria-invalid="true">
  <option value="">Escolha um país</option>
  <option value="pt">Portugal</option>
  <option value="us">Estados Unidos</option>
  <option value="uk">Reino Unido</option>
  <option value="ca">Canadá</option>
</go-native-select>

Integração em formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Com required, o submit é bloqueado até haver uma escolha; o valor é submetido via FormData através do name.

Submeter 
<form>
  <go-native-select name="country" required>
    <option value="">Escolha um país</option>
    <option value="pt">Portugal</option>
    <option value="us">Estados Unidos</option>
    <option value="uk">Reino Unido</option>
  </go-native-select>
  <go-button type="submit">Submeter</go-button>
</form>

Acessibilidade

O componente mantém todas as funcionalidades de acessibilidade nativas do <select>. Usa aria-label ou aria-labelledby para contexto adicional quando necessário; o chevron está marcado como aria-hidden para não duplicar leitura. 

<go-native-select aria-label="Escolha o idioma preferido">
  <option value="pt">Português</option>
  <option value="en">Inglês</option>
  <option value="es">Espanhol</option>
  <option value="fr">Francês</option>
</go-native-select>
