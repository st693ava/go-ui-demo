Skeleton

Usa-se para mostrar um marcador enquanto o conteúdo carrega.

Anterior Separator Seguinte Button 
<div class="row">
  <go-skeleton circle width="3rem" height="3rem"></go-skeleton>
  <div class="lines">
    <go-skeleton width="250px" height="1rem"></go-skeleton>
    <go-skeleton width="200px" height="1rem"></go-skeleton>
  </div>
</div>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-skeleton> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Os atributos width e height aceitam qualquer valor CSS (px, rem, %) e são aplicados via estilo inline. O atributo circle torna-o redondo (placeholder de avatar) e radius aceita none, sm, md, lg, xl ou full. A animação de pulsação vem da skin. 

<go-skeleton width="100px" height="20px" radius="full"></go-skeleton>
<go-skeleton width="100px" height="20px" radius="full"></go-skeleton>

Exemplos

Esqueleto

Réplica do demo shadcn-vue: um avatar circular e duas linhas de texto a carregar. A forma redonda vem do atributo circle do próprio componente — sem CSS local. 

<div class="row">
  <go-skeleton circle width="3rem" height="3rem"></go-skeleton>
  <div class="lines">
    <go-skeleton width="250px" height="1rem"></go-skeleton>
    <go-skeleton width="200px" height="1rem"></go-skeleton>
  </div>
</div>

Cartão a carregar

Esqueleto de um cartão: imagem de destaque e três linhas de texto — o aspeto típico de um placeholder de conteúdo. 

<div class="card">
  <go-skeleton radius="lg" width="100%" height="8rem"></go-skeleton>
  <div class="lines">
    <go-skeleton width="80%" height="1rem"></go-skeleton>
    <go-skeleton width="60%" height="1rem"></go-skeleton>
    <go-skeleton width="40%" height="1rem"></go-skeleton>
  </div>
</div>
