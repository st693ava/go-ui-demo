Input

Apresenta um campo de formulário ou um componente com o aspeto de um campo de entrada.

Anterior Switch Seguinte Textarea 
<go-input name="email" type="email" placeholder="E-mail"></go-input>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-input> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O atributo type aceita qualquer tipo nativo (text, email, password, number, file…). O name liga o valor ao <form> nativo via ElementInternals (FACE); required faz a validação viver no host. 

<go-input name="email" type="email" placeholder="E-mail"></go-input>
<go-input name="email" type="email" placeholder="E-mail"></go-input>

Exemplos

Por defeito

Um campo de entrada simples.

<go-input name="email" type="email" placeholder="E-mail"></go-input>

Ficheiro

Um campo de carregamento de ficheiro com type="file", composto com uma <go-label> ao nível da página. O seletor de ficheiros nativo renderiza com a skin; a submissão do ficheiro via FACE não está coberta (usa um <input type="file"> nativo se precisares do binário no <form>).

Imagem 
<go-label for="picture">Imagem</go-label>
<go-input name="picture" type="file"></go-input>

Desativado

Um campo desativado: o atributo disabled impede a edição e remove o valor da submissão. 

<go-input name="email" type="email" placeholder="E-mail" disabled></go-input>

Com etiqueta

Um campo com etiqueta: compõe <go-label> com <go-input> ao nível da página.

E-mail 
<go-label for="email">E-mail</go-label>
<go-input name="email" type="email" placeholder="E-mail"></go-input>

Com botão

Um campo com botão: compõe <go-input> com <go-button> numa linha para uma ação inline (ex.: subscrever).

Subscrever 
<div class="row">
  <go-input name="email" type="email" placeholder="E-mail"></go-input>
  <go-button type="submit">Subscrever</go-button>
</div>
