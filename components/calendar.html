Calendar

Um componente de data que permite selecionar e editar uma data.

Anterior Carousel Seguinte Resizable 
<go-calendar></go-calendar>

Sobre

O <go-calendar> assenta no Calendar da Reka UI, que usa o pacote @internationalized/date para tratar datas. É self-contained: arranca sem valor pré-selecionado e a seleção é comunicada via evento change. Os atributos locale e layout são reencaminhados para o componente Reka subjacente.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-calendar> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Coloca <go-calendar> e ouve o evento change; o detail é a data ISO (AAAA-MM-DD) selecionada. 

<go-calendar></go-calendar>
document
  .querySelector('go-calendar')
  .addEventListener('change', (e) => {
    console.log(e.detail) // "2026-05-17"
  })

Exemplos

Data selecionada

O evento change dispara a cada seleção. Aqui ligamos a data escolhida a um campo de texto.

Nenhuma data selecionada.

<go-calendar id="cal"></go-calendar>
<p id="out">Nenhuma data selecionada.</p>

Localização

Usa o atributo locale para mudar os nomes de meses e dias e a ordem da semana. Aqui o calendário em português (locale="pt"); o sistema gregoriano é o default. 

<go-calendar locale="pt"></go-calendar>

Seletor de mês e ano

Com layout="month-and-year" o cabeçalho passa a dropdowns de mês e ano, para navegar datas distantes mais depressa. 

<go-calendar locale="pt" layout="month-and-year"></go-calendar>
