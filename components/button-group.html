Button Group

Um contentor que agrupa botões relacionados com estilo consistente.

Anterior Button Seguinte Label
Arquivar Reportar Adiar 
<go-button-group aria-label="Ações de email">
  <go-button variant="outline">Arquivar</go-button>
  <go-button variant="outline">Reportar</go-button>
  <go-button variant="outline">Adiar</go-button>
</go-button-group>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-button-group> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Coloca os teus <go-button> directamente dentro de <go-button-group>. O contentor cola as bordas e os cantos dos botões adjacentes para formar um grupo coeso. 

<go-button-group>
  <go-button>Botão 1</go-button>
  <go-button>Botão 2</go-button>
</go-button-group>
Botão 1 Botão 2 
<go-button-group>
  <go-button>Botão 1</go-button>
  <go-button>Botão 2</go-button>
</go-button-group>

Exemplos

Orientação

Define a prop orientation para mudar o eixo do grupo de botões para vertical.

+ − 
<go-button-group orientation="vertical" aria-label="Controlos de média">
  <go-button variant="outline" size="icon">+</go-button>
  <go-button variant="outline" size="icon">−</go-button>
</go-button-group>

Tamanho

Controla o tamanho dos botões através da prop size em cada <go-button> individual.

Pequeno Botão Grupo Default Botão Grupo Grande Botão Grupo 
<go-button-group>
  <go-button variant="outline" size="sm">Pequeno</go-button>
  <go-button variant="outline" size="sm">Botão</go-button>
  <go-button variant="outline" size="sm">Grupo</go-button>
</go-button-group>

Aninhado

Aninha vários <go-button-group> para criar grupos de botões com espaçamento entre os subgrupos.

1 2 3 4 5 ‹ › 
<go-button-group>
  <go-button-group>
    <go-button variant="outline" size="sm">1</go-button>
    <go-button variant="outline" size="sm">2</go-button>
    <go-button variant="outline" size="sm">3</go-button>
  </go-button-group>
  <go-button-group>
    <go-button variant="outline" size="icon" aria-label="Anterior">‹</go-button>
    <go-button variant="outline" size="icon" aria-label="Seguinte">›</go-button>
  </go-button-group>
</go-button-group>

Separador

Botões com variante outline não precisam de separador, pois já têm borda. Para outras variantes, intercala um divisor para melhorar a hierarquia visual.

Copiar Colar 
<go-button-group>
  <go-button variant="secondary" size="sm">Copiar</go-button>
  <go-separator orientation="vertical"></go-separator>
  <go-button variant="secondary" size="sm">Colar</go-button>
</go-button-group>

Split

Cria um botão dividido (split) adicionando dois botões separados por um divisor — uma ação principal e uma ação secundária.

Botão + 
<go-button-group>
  <go-button variant="secondary">Botão</go-button>
  <go-separator orientation="vertical"></go-separator>
  <go-button variant="secondary" size="icon">+</go-button>
</go-button-group>
