Um componente interativo que expande e colapsa um painel.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-collapsible> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <span slot="trigger"> é o botão que alterna o painel; tudo o resto dentro de <go-collapsible> é o conteúdo colapsável. Usa o atributo default-open para começar expandido. 

<go-collapsible>
  <span slot="trigger">Posso usar isto no meu projeto?</span>
  Sim. Livre para uso pessoal e comercial. Sem necessidade de
  atribuição.
</go-collapsible>

</go-collapsible>
