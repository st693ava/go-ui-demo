Switch

Um controlo que permite ao utilizador alternar entre ligado e desligado.

<go-switch name="airplane-mode">Modo avião</go-switch>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-switch> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo do elemento é a etiqueta — clicar no texto também alterna o estado. Usa checked para começar ligado. O atributo name liga o valor ao <form> nativo via ElementInternals (FACE). Quando ligado, submete on (ou o value que definires). 

<go-switch name="airplane-mode">Modo avião</go-switch>

<go-switch name="airplane-mode">Modo avião</go-switch>

Exemplos

Com texto de apoio

Compõe o switch com um parágrafo descritivo ao nível da página para explicar o que liga ou desliga.

E-mails de marketing

Recebe e-mails sobre novos produtos, funcionalidades e novidades. 

<div class="field">
  <go-switch name="marketing">E-mails de marketing</go-switch>
  <p class="hint">Recebe e-mails sobre novos produtos, funcionalidades e novidades.</p>
</div>

Desativado

O atributo disabled impede a interação e remove o valor da submissão do formulário.

Funcionalidades beta 
<go-switch name="beta" disabled>Funcionalidades beta</go-switch>

Lista de definições

Vários switches numa lista de preferências, cada um com a sua etiqueta e descrição. O atributo checked define o estado inicial de cada um.

Notificações push

Alertas no dispositivo em tempo real.

Resumo semanal

Um e-mail com a atividade da semana.

<div class="row">
  <div>
    <strong>Notificações push</strong>
    <p>Alertas no dispositivo em tempo real.</p>
  </div>
  <go-switch name="push" checked></go-switch>
</div>

Num formulário

Como FACE form-input, a <go-switch> participa na submissão do <form> nativo pelo seu name — sem JavaScript de ligação.

Modo avião Wi-Fi Guardar {} 
<form>
  <go-switch name="airplane">Modo avião</go-switch>
  <go-switch name="wifi">Wi-Fi</go-switch>
  <go-button type="submit">Guardar</go-button>
</form>
