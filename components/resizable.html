Resizable

Grupos de painéis e layouts redimensionáveis e acessíveis, com suporte de teclado.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-resizable> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section> é um painel. As pegas de redimensionamento são inseridas automaticamente entre painéis. Usa direction para horizontal (default) ou vertical. 

<go-resizable direction="horizontal">
  <section>Um</section>
  <section>Dois</section>
</go-resizable>

Exemplos

Vertical

Usa direction="vertical" para empilhar os painéis e redimensionar na vertical.

Cabeçalho
Conteúdo 
<go-resizable direction="vertical">
  <section>Cabeçalho</section>
  <section>Conteúdo</section>
</go-resizable>

Três painéis

Adiciona quantas <section> precisares; cada nova secção ganha automaticamente a sua pega de redimensionamento.

Navegação
Lista
Detalhe 
<go-resizable direction="horizontal">
  <section>Navegação</section>
  <section>Lista</section>
  <section>Detalhe</section>
</go-resizable>

Pega

O <go-resizable> mostra sempre uma pega visível entre painéis (equivalente ao withHandle do shadcn-vue), arrastável com o rato e navegável por teclado.
