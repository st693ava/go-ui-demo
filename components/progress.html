Progress

Mostra um indicador do progresso de conclusão de uma tarefa, tipicamente como uma barra de progresso.

Anterior Table Seguinte Accordion 
<go-progress value="13" id="p"></go-progress>

<script>
  setTimeout(() => {
    document.getElementById('p').setAttribute('value', '66')
  }, 500)
</script>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-progress> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O atributo value reflete o progresso de 0 a 100. Atualiza-o dinamicamente via JavaScript para animar a barra. 

<go-progress value="33"></go-progress>
<go-progress value="33"></go-progress>

Exemplos

Níveis

Vários valores de progresso, de vazio a completo. 

<go-progress value="0"></go-progress>
<go-progress value="25"></go-progress>
<go-progress value="50"></go-progress>
<go-progress value="75"></go-progress>
<go-progress value="100"></go-progress>

Animado

O value arranca em 13 e sobe para 66 após meio segundo — atualizando o atributo via JavaScript, tal como no demo original do shadcn-vue. 

<go-progress value="13" id="p"></go-progress>

<script>
  setTimeout(() => {
    document.getElementById('p').setAttribute('value', '66')
  }, 500)
</script>

Com etiqueta

Compõe a barra com texto à volta para indicar a percentagem e o contexto da tarefa.

A enviar ficheiros… 72% 
<div class="field">
  <div class="head">
    <span>A enviar ficheiros…</span>
    <span>72%</span>
  </div>
  <go-progress value="72"></go-progress>
</div>
