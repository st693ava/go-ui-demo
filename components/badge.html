Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-badge> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo do selo é o HTML por defeito do elemento. O atributo variant aceita default, secondary, destructive ou outline. Com as-child e uma única <a> filha, a skin aplica-se ao próprio link. 

<go-badge variant="secondary">Badge</go-badge>

Ligação

Usa o atributo as-child para dar a uma <a> o aspeto de selo — equivalente real ao as-child do shadcn-vue. A skin é aplicada ao próprio link, preservando o href e a navegação nativa.

Badge 
<go-badge as-child>
  <a href="#">Badge</a>
</go-badge>
