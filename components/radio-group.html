Radio Group

Um conjunto de botões selecionáveis — botões de rádio — em que no máximo um pode estar selecionado de cada vez.

<go-radio-group name="density" value="comfortable">
  <option value="default">Padrão</option>
  <option value="comfortable">Confortável</option>
  <option value="compact">Compacto</option>
</go-radio-group>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-radio-group> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="x">Etiqueta</option> é uma opção do grupo. O atributo value no <go-radio-group> define a opção inicial; o name liga-o a um formulário (FACE) e required bloqueia o submit se nada estiver selecionado. 

<go-radio-group name="density" value="comfortable">
  <option value="default">Padrão</option>
  <option value="comfortable">Confortável</option>
  <option value="compact">Compacto</option>
</go-radio-group>
<go-radio-group name="density" value="comfortable">
  <option value="default">Padrão</option>
  <option value="comfortable">Confortável</option>
  <option value="compact">Compacto</option>
</go-radio-group>

Exemplos

Default

O exemplo base do shadcn-vue: três opções com a opção Confortável pré-selecionada via atributo value (equivalente ao default-value). 

<go-radio-group name="density" value="comfortable">
  <option value="default">Padrão</option>
  <option value="comfortable">Confortável</option>
  <option value="compact">Compacto</option>
</go-radio-group>

Opção desativada

Marca um <option disabled> individual para o tornar não-selecionável, mantendo as restantes ativas. 

<go-radio-group name="plan" value="free">
  <option value="free">Gratuito</option>
  <option value="pro">Pro</option>
  <option value="enterprise" disabled>Enterprise (esgotado)</option>
</go-radio-group>

Grupo desativado

O atributo disabled no host desativa o grupo inteiro. 

<go-radio-group name="ship" value="standard" disabled>
  <option value="standard">Standard</option>
  <option value="express">Expresso</option>
</go-radio-group>

Formulário

Como é um Custom Element Form-Associated, integra-se diretamente num <form> nativo. Com required, o submit é bloqueado até haver uma opção selecionada.

Submeter 
<form>
  <go-radio-group name="plan" required>
    <option value="free">Gratuito</option>
    <option value="pro">Pro</option>
    <option value="team">Equipa</option>
  </go-radio-group>
  <go-button type="submit">Submeter</go-button>
</form>
