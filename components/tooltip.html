Tooltip

Um popup que mostra informação relacionada com um elemento quando este recebe foco de teclado ou o rato passa por cima.

Adicionar à biblioteca
 
<go-tooltip>
  <go-button slot="trigger" variant="outline">Apontar</go-button>
  <div slot="content">Adicionar à biblioteca</div>
</go-tooltip>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-tooltip> incluído. O provider de tooltips é montado internamente: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O slot="trigger" é o elemento alvo; o texto da dica vem do slot="content" (ou de qualquer markup sem slot, como defaultHtml). O contexto de provider exigido pelo motor é montado dentro do próprio <go-tooltip> — não precisas de o declarar. 

<go-tooltip>
  <go-button slot="trigger">Apontar</go-button>
  <div slot="content">Adicionar à biblioteca</div>
</go-tooltip>

Conteúdo por defeito

Sem slot="content", qualquer markup que não seja o gatilho serve de texto da dica (defaultHtml).
