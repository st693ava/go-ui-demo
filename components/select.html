Select

Mostra uma lista de opções para o utilizador escolher — acionada por um botão.

Anterior Radio Group Seguinte Number Field 
<go-select name="fruit" placeholder="Selecione uma fruta">
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
  <option value="blueberry">Mirtilo</option>
  <option value="grapes">Uvas</option>
  <option value="pineapple">Ananás</option>
</go-select>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-select> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="x">Etiqueta</option> é um item da lista. O atributo placeholder define o texto antes da escolha, value pré-seleciona um item e name liga-o ao formulário (FACE). 

<go-select name="fruit" placeholder="Selecione uma fruta">
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
  <option value="blueberry">Mirtilo</option>
  <option value="grapes">Uvas</option>
  <option value="pineapple">Ananás</option>
</go-select>

Exemplos

Default

O exemplo base: um select com placeholder e cinco opções. 

<go-select name="fruit" placeholder="Selecione uma fruta">
  <option value="apple">Maçã</option>
  <option value="banana">Banana</option>
  <option value="blueberry">Mirtilo</option>
  <option value="grapes">Uvas</option>
  <option value="pineapple">Ananás</option>
</go-select>

Scrollable

Com muitas opções, a lista do dropdown rola automaticamente. Aqui um seletor de fuso horário com dezenas de itens. 

<go-select name="tz" placeholder="Selecione um fuso horário">
  <option value="est">Eastern Standard Time (EST)</option>
  <option value="cst">Central Standard Time (CST)</option>
  <option value="mst">Mountain Standard Time (MST)</option>
  <option value="pst">Pacific Standard Time (PST)</option>
  <option value="gmt">Greenwich Mean Time (GMT)</option>
  <option value="cet">Central European Time (CET)</option>
  <option value="jst">Japan Standard Time (JST)</option>
  <option value="brt">Brasilia Time (BRT)</option>
  <!-- ...mais opções -->
</go-select>

Opção desativada

Marca um <option disabled> para o tornar não-selecionável dentro da lista. 

<go-select name="tier" placeholder="Selecione um plano">
  <option value="free">Gratuito</option>
  <option value="pro">Pro</option>
  <option value="enterprise" disabled>Enterprise (indisponível)</option>
</go-select>

Formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Com required, o submit é bloqueado até haver uma escolha.

Submeter 
<form>
  <go-select name="fruit" required placeholder="Escolha…">
    <option value="apple">Maçã</option>
    <option value="banana">Banana</option>
    <option value="grapes">Uvas</option>
  </go-select>
  <go-button type="submit">Submeter</go-button>
</form>
