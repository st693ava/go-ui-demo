pnpm add github:st693ava/go-ui-web-components

bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-toaster> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <go-toaster> monta-se uma única vez na raiz da app. Os toasts disparam-se imperativamente via window.goToast(...) — singleton que funciona enquanto houver um <go-toaster> montado. 

<!-- raiz da app -->
<go-toaster position="bottom-right"></go-toaster>
// em qualquer sítio
window.goToast('A minha primeira notificação')

Exemplos

Tipos

Os métodos success, info, warning e error aplicam o estilo correspondente ao toast. promise mostra um estado de carregamento até a promessa resolver.

Default Sucesso Info Aviso Erro Promise 
window.goToast('O evento foi criado')
window.goToast.success('O evento foi criado')
window.goToast.info('Chega 10 minutos antes da hora do evento')
window.goToast.warning('A hora de início não pode ser anterior às 8h')
window.goToast.error('O evento não foi criado')
window.goToast.promise(
  () => new Promise((r) => setTimeout(() => r({ name: 'Evento' }), 2000)),
  { loading: 'A carregar...', success: (d) => `${d.name} foi criado`, error: 'Erro' },
)

Com dialog

Dispara um toast a partir de uma ação dentro de um <go-dialog>; o toaster está montado na raiz, por isso a notificação aparece sobre o conteúdo.
