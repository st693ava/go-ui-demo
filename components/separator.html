Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-separator> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Por defeito o separador é horizontal. O atributo orientation="vertical" torna-o vertical — nesse caso deve estar dentro de um contentor flex com altura definida. 

<go-separator></go-separator>
<go-separator orientation="vertical"></go-separator>
