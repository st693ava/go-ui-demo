Alert Dialog

Um diálogo modal que interrompe o utilizador com conteúdo importante e espera uma resposta.

Anterior Dialog Seguinte Drawer
Mostrar diálogo
Tens a certeza absoluta?
Esta ação não pode ser anulada. Vai apagar a tua conta permanentemente e remover os teus dados dos nossos servidores. 
<go-alert-dialog>
  <span slot="trigger">Mostrar diálogo</span>
  <div slot="title">Tens a certeza absoluta?</div>
  <div slot="description">
    Esta ação não pode ser anulada. Vai apagar a tua conta
    permanentemente e remover os teus dados dos nossos servidores.
  </div>
  <div slot="footer">
    <button>Cancelar</button>
    <button>Continuar</button>
  </div>
</go-alert-dialog>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-alert-dialog> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <span slot="trigger"> abre o diálogo. As regiões nomeadas são slot="title", slot="description", slot="content" e slot="footer" — no rodapé colocas os botões de cancelar e confirmar. Ao contrário do Dialog, este é modal e exige uma resposta explícita. 

<go-alert-dialog>
  <span slot="trigger">Abrir</span>
  <div slot="title">Tens a certeza absoluta?</div>
  <div slot="description">
    Esta ação não pode ser anulada.
  </div>
  <div slot="footer">
    <button>Cancelar</button>
    <button>Continuar</button>
  </div>
</go-alert-dialog>

Exemplos

Confirmação

O caso de uso central: pedir confirmação de uma ação destrutiva antes de a executar.

Apagar conta
Tens a certeza absoluta?
Esta ação não pode ser anulada. A tua conta e todos os dados associados serão removidos permanentemente. 
<go-alert-dialog>
  <span slot="trigger">Apagar conta</span>
  <div slot="title">Tens a certeza absoluta?</div>
  <div slot="description">
    Esta ação não pode ser anulada. A tua conta e todos os
    dados associados serão removidos permanentemente.
  </div>
  <div slot="footer">
    <button>Cancelar</button>
    <button>Sim, apagar conta</button>
  </div>
</go-alert-dialog>

Com conteúdo

O slot="content" permite acrescentar detalhe entre a descrição e o rodapé — por exemplo, o impacto exato da ação.

Remover repositório
Remover este repositório?
Esta operação é definitiva e afeta os seguintes recursos:
  • 14 issues abertas
  • 3 pull requests por rever
  • 2 webhooks ativos
 
<go-alert-dialog>
  <span slot="trigger">Remover repositório</span>
  <div slot="title">Remover este repositório?</div>
  <div slot="description">
    Esta operação é definitiva e afeta os seguintes recursos:
  </div>
  <div slot="content">
    <ul>
      <li>14 issues abertas</li>
      <li>3 pull requests por rever</li>
      <li>2 webhooks ativos</li>
    </ul>
  </div>
  <div slot="footer">
    <button>Cancelar</button>
    <button>Remover</button>
  </div>
</go-alert-dialog>

Sair sem guardar

Interrompe uma navegação que perderia alterações por gravar, dando ao utilizador a hipótese de voltar atrás.

Descartar rascunho
Descartar alterações?
Tens alterações por guardar. Se saíres agora, perdes o rascunho atual. 
<go-alert-dialog>
  <span slot="trigger">Descartar rascunho</span>
  <div slot="title">Descartar alterações?</div>
  <div slot="description">
    Tens alterações por guardar. Se saíres agora, perdes o
    rascunho atual.
  </div>
  <div slot="footer">
    <button>Continuar a editar</button>
    <button>Descartar</button>
  </div>
</go-alert-dialog>
