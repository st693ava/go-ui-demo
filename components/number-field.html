Number Field

Um campo numérico permite ao utilizador introduzir um número e incrementá-lo ou decrementá-lo com botões de stepper.

<go-number-field name="age" value="18" min="0"></go-number-field>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-number-field> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define o valor inicial com value e limita o intervalo com min, max e step (passo do stepper). O name liga-o a um formulário (FACE) e required bloqueia o submit se estiver vazio. 

<go-number-field name="age" value="18" min="0"></go-number-field>
<go-number-field name="age" value="18" min="0"></go-number-field>

Exemplos

Default

O exemplo base: valor inicial e mínimo definidos por atributo. 

<go-number-field name="age" value="18" min="0"></go-number-field>

Disabled

O atributo disabled impede edição e desativa os botões de stepper. 

<go-number-field name="age" value="18" disabled></go-number-field>

Passo

O atributo step controla o incremento. Aqui um campo que sobe e desce de 5 em 5, com limites mínimo e máximo. Nota: o <go-number-field> usa stepper numérico simples — formatação de moeda/percentagem (Intl) não está exposta pela API atual. 

<go-number-field name="qty" value="10" min="0" max="100" step="5"></go-number-field>

Formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Com required, o submit é bloqueado enquanto o campo estiver vazio.

Pagamento Submeter 
<form>
  <go-label>Pagamento</go-label>
  <go-number-field name="payment" value="10" min="10" max="5000" required></go-number-field>
  <go-button type="submit">Submeter</go-button>
</form>
