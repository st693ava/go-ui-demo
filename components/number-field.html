Number Field

Um campo numérico permite ao utilizador introduzir um número e incrementá-lo ou decrementá-lo com botões de stepper.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-number-field> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define o valor inicial com value e limita o intervalo com min, max e step (passo do stepper). Para formatação, usa format="decimal", format="percent" ou format="currency" (com currency="EUR") — mapeado para Intl.NumberFormat. O name liga-o a um formulário (FACE) e required bloqueia o submit se estiver vazio. 

<go-number-field name="age" value="18" min="0"></go-number-field>
<go-number-field name="age" value="18" min="0"></go-number-field>

Exemplos

Default

O exemplo base: valor inicial e mínimo definidos por atributo. 

<go-number-field name="age" value="18" min="0"></go-number-field>

Disabled

O atributo disabled impede edição e desativa os botões de stepper. 

<go-number-field name="age" value="18" disabled></go-number-field>

Decimal

Com format="decimal" o campo aceita casas decimais. min-fraction-digits força um número mínimo de casas e sign-display="exceptZero" mostra o sinal exceto no zero. 

<go-number-field
  name="number"
  value="5"
  format="decimal"
  min-fraction-digits="1"
  sign-display="exceptZero"
></go-number-field>

Percentagem

Com format="percent" o valor é apresentado como percentagem (0.05 → 5%). Combina com step para definir o incremento. 

<go-number-field
  name="percent"
  value="0.05"
  step="0.01"
  format="percent"
></go-number-field>

Moeda

Com format="currency" e currency="EUR" o campo formata como moeda. currency-display="code" mostra o código ISO e currency-sign="accounting" usa a convenção contabilística para valores negativos. 

<go-number-field
  name="balance"
  value="1500"
  format="currency"
  currency="EUR"
  currency-display="code"
  currency-sign="accounting"
></go-number-field>

Formulário

Como Custom Element Form-Associated, integra-se num <form> nativo. Aqui um campo de pagamento em euros, entre 10 e 5000; com required o submit é bloqueado enquanto o campo estiver vazio.

Pagamento Introduza um valor entre 10 e 5000. Submeter 
<form>
  <go-label>Pagamento</go-label>
  <go-number-field
    name="payment" value="10" min="10" max="5000"
    format="currency" currency="EUR"
    currency-display="code" currency-sign="accounting" required
  ></go-number-field>
  <go-button type="submit">Submeter</go-button>
</form>
