Scroll Area

Aumenta a funcionalidade de scroll nativa com estilo personalizado e consistente entre browsers.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-scroll-area> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo entra no slot nativo do <go-scroll-area> e é scrollável dentro do viewport. Define a caixa com os atributos height e width (qualquer unidade CSS). 

<go-scroll-area height="200px" width="350px">
  Conteúdo longo que ultrapassa a altura definida…
</go-scroll-area>
O Jokester começou a esgueirar-se para o castelo a meio da noite e a deixar piadas por todo o lado: debaixo da almofada do rei, na sopa, até na casa de banho real. O rei estava furioso, mas não conseguia parar o Jokester. E então, um dia, o rei tropeçou numa das almofadas-pum do Jokester e caiu no fosso. Ficou tão envergonhado que decidiu nomear o Jokester bobo oficial da corte. 
<go-scroll-area height="9rem" width="22rem">
  <div class="content">O Jokester começou a esgueirar-se…</div>
</go-scroll-area>

Exemplos

Vertical

Lista vertical de 50 tags com um separador entre cada uma — scroll na vertical quando o conteúdo ultrapassa a altura. Os itens são gerados em JavaScript, tal como no demo original do shadcn-vue.

Tags

 
<go-scroll-area height="18rem" width="12rem">
  <div class="content"><h4>Tags</h4><div id="list"></div></div>
</go-scroll-area>

<script>
  const list = document.getElementById('list')
  for (let i = 50; i >= 1; i--) {
    const item = document.createElement('div')
    item.className = 'sa-item'
    item.textContent = `v1.2.0-beta.${i}`
    list.append(item, document.createElement('hr'))
  }
</script>

Horizontal

Conteúdo numa única linha mais larga do que a caixa — scroll na horizontal. 

<go-scroll-area height="9rem" width="22rem">
  <div class="row">
    <figure>…</figure>
    <figure>…</figure>
    <!-- … -->
  </div>
</go-scroll-area>
