Dropdown Menu

Mostra um menu ao utilizador — como um conjunto de ações ou funções — acionado por um botão.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-dropdown-menu> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo de <span slot="trigger"> é o botão que abre o menu. Cada <option value="x">Etiqueta</option> é um item; ao selecionar, o elemento dispara um evento select com detail.value. Atributos declarativos opcionais: shortcut="⌘P" mostra um atalho, disabled desativa o item, type="label" cria um rótulo de grupo, type="separator" insere um divisor e uma <section title="..."> aninhada vira um submenu. 

<go-dropdown-menu>
  <span slot="trigger">Abrir</span>
  <option type="label">A minha conta</option>
  <option value="perfil" shortcut="⇧⌘P">Perfil</option>
  <option type="separator"></option>
  <section title="Convidar">
    <option value="email">Email</option>
  </section>
</go-dropdown-menu>
document
  .querySelector('go-dropdown-menu')
  .addEventListener('select', (e) => {
    console.log(e.detail.value) // 'perfil' | 'faturacao' | ...
  })

Exemplos

Menu de conta

Um menu com rótulo, atalhos e separadores — as ações típicas de uma conta de utilizador. O <span slot="trigger"> estiliza-se livremente como qualquer botão.

A minha conta 
<go-dropdown-menu>
  <span slot="trigger">A minha conta</span>
  <option type="label">A minha conta</option>
  <option value="perfil" shortcut="⇧⌘P">Perfil</option>
  <option value="faturacao" shortcut="⌘B">Faturação</option>
  <option value="definicoes" shortcut="⌘S">Definições</option>
  <option type="separator"></option>
  <option value="terminar" shortcut="⇧⌘Q">Terminar sessão</option>
</go-dropdown-menu>

Submenu

Uma <section title="..."> aninhada torna-se um submenu que abre lateralmente ao passar o rato.

Equipa 
<go-dropdown-menu>
  <span slot="trigger">Equipa</span>
  <option value="membros">Membros</option>
  <section title="Convidar utilizadores">
    <option value="email">Email</option>
    <option value="mensagem">Mensagem</option>
    <option value="mais-convite">Mais…</option>
  </section>
  <option value="nova-equipa" shortcut="⌘+T">Nova equipa</option>
</go-dropdown-menu>

Item desativado

Marca um item com o atributo disabled para o tornar não selecionável, mantendo-o visível no menu.

Ações 
<go-dropdown-menu>
  <span slot="trigger">Ações</span>
  <option value="editar">Editar</option>
  <option value="duplicar">Duplicar</option>
  <option value="arquivar" disabled>Arquivar</option>
  <option value="eliminar">Eliminar</option>
</go-dropdown-menu>

Trigger com ícone

O slot trigger aceita qualquer HTML — incluindo um ícone ou um avatar — para integrar o menu numa barra de ações.

⋯ 
<go-dropdown-menu>
  <span slot="trigger" aria-label="Mais opções">⋯</span>
  <option value="ver">Ver detalhes</option>
  <option value="partilhar">Partilhar</option>
  <option value="exportar">Exportar</option>
</go-dropdown-menu>
