Date Picker

Seletor de data com presets, construído pela composição dos componentes Popover e Calendar.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-date-picker> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O Date Picker compõe internamente um Popover com um Calendar. O botão mostra a data formatada em PT-PT ou o placeholder; ao escolher um dia, o popover fecha e dispara o evento change com a data em ISO (detail.value). 

<go-date-picker placeholder="Escolher data"></go-date-picker>

<script>
  document
    .querySelector('go-date-picker')
    .addEventListener('change', (e) => {
      console.log(e.detail.value) // "2026-05-20"
    })
</script>
<go-date-picker placeholder="Escolher data"></go-date-picker>

Exemplos

Date Picker

O exemplo base: um botão com ícone de calendário que abre o Calendar dentro de um Popover alinhado ao início. 

<go-date-picker></go-date-picker>

Valor inicial

Usa o atributo value com uma data ISO (AAAA-MM-DD) para pré-selecionar uma data; o botão mostra-a logo formatada. 

<go-date-picker value="2026-01-20"></go-date-picker>

Presets

Adiciona <option value="AAAA-MM-DD">Etiqueta</option> como filhos para oferecer atalhos rápidos por cima do calendário. Cada preset é um botão real que define a data e fecha o popover. 

<go-date-picker placeholder="Selecionar data">
  <option value="2026-05-18">Hoje</option>
  <option value="2026-05-19">Amanhã</option>
  <option value="2026-05-25">Daqui a uma semana</option>
  <option value="2026-06-17">Daqui a um mês</option>
</go-date-picker>

Locale

O atributo locale controla os nomes de meses/dias do calendário e o formato da data no botão. Default pt; usa en para inglês. 

<go-date-picker locale="en" value="2026-03-14"></go-date-picker>
