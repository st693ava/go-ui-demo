Breadcrumb

Mostra o caminho até ao recurso atual usando uma hierarquia de links.

Anterior Tooltip Seguinte Dropdown Menu 
<go-breadcrumb collapse="2">
  <option value="/">Início</option>
  <option value="/docs">Documentação</option>
  <option value="/docs/building">A construir a app</option>
  <option value="/docs/components">Componentes</option>
  <option value="/docs/components/breadcrumb">Breadcrumb</option>
</go-breadcrumb>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-breadcrumb> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="/url">Etiqueta</option> é um nível do trilho. O último torna-se a página atual (sem link); os restantes são links navegáveis. 

<go-breadcrumb>
  <option value="/">Início</option>
  <option value="/components">Componentes</option>
  <option value="/components/breadcrumb">Breadcrumb</option>
</go-breadcrumb>
<go-breadcrumb>
  <option value="/">Início</option>
  <option value="/components">Componentes</option>
  <option value="/components/breadcrumb">Breadcrumb</option>
</go-breadcrumb>

Exemplos

Separador personalizado

Usa o atributo separator para substituir o chevron por defeito por um caráter à tua escolha. 

<go-breadcrumb separator="/">
  <option value="/">Início</option>
  <option value="/components">Componentes</option>
  <option value="/components/breadcrumb">Breadcrumb</option>
</go-breadcrumb>

Dropdown

Compõe um nível do trilho com <go-dropdown-menu> para um crumb com menu.

Início / Componentes ▾ / Breadcrumb 
<nav class="bc" aria-label="breadcrumb">
  <a href="/">Início</a>
  <span>/</span>
  <go-dropdown-menu>
    <span slot="trigger">Componentes ▾</span>
    <option value="docs">Documentação</option>
    <option value="themes">Temas</option>
    <option value="github">GitHub</option>
  </go-dropdown-menu>
  <span>/</span>
  <span aria-current="page">Breadcrumb</span>
</nav>

Colapsado

O atributo collapse esconde o meio do trilho com uma reticência, mantendo o primeiro nível e os N últimos (default 2). 

<go-breadcrumb collapse="2">
  <option value="/">Início</option>
  <option value="/docs">Documentação</option>
  <option value="/docs/building">A construir a app</option>
  <option value="/docs/components">Componentes</option>
  <option value="/docs/components/breadcrumb">Breadcrumb</option>
</go-breadcrumb>

Componente de link

Os níveis do trilho são <a href> nativos — sem acoplamento a nenhum router. Para SPA, interceta o clique e delega ao router do teu framework; o markup mantém-se idêntico. 

// SPA: delega a navegação ao router (Vue/React/etc.)
document
  .querySelector('go-breadcrumb')
  .addEventListener('click', (e) => {
    const a = e.target.closest('a[href]')
    if (!a) return
    e.preventDefault()
    router.push(a.getAttribute('href'))
  })

Responsivo

Trilho que colapsa o meio num menu acessível. Em ecrãs largos abre um <go-dropdown-menu>; o crumb final trunca em ecrãs estreitos.

Início / … / Caching e revalidação 
<nav class="bc" aria-label="breadcrumb">
  <a href="/">Início</a>
  <span>/</span>
  <go-dropdown-menu>
    <span slot="trigger" aria-label="Alternar menu">…</span>
    <option value="/docs">Documentação</option>
    <option value="/docs/building">A construir a app</option>
    <option value="/docs/data">Obtenção de dados</option>
  </go-dropdown-menu>
  <span>/</span>
  <span class="truncate" aria-current="page">Caching e revalidação</span>
</nav>
