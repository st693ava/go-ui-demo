npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components

bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-tabs> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section title="..." value="...">…</section> é um separador: title é o rótulo do botão e o conteúdo interno é o painel. O atributo default-value escolhe o separador ativo inicial (por defeito o primeiro). 

<go-tabs default-value="account">
  <section title="Conta" value="account">
    Faz alterações à tua conta aqui.
  </section>
  <section title="Palavra-passe" value="password">
    Altera a tua palavra-passe aqui.
  </section>
</go-tabs>

Separador desativado

Adiciona disabled a uma <section> para impedir a seleção desse separador.

Definições gerais da aplicação.
Disponível apenas em planos pagos.
Opções avançadas para programadores.

  </section>
