Command

Menu de comandos rápido, componível e sem estilo imposto para Vue.

<go-command>
  <section title="Sugestões">
    <option value="calendario">Calendário</option>
    <option value="emoji">Procurar emoji</option>
    <option value="calculadora" disabled>Calculadora</option>
  </section>
  <section title="Definições">
    <option value="perfil" shortcut="⌘P">Perfil</option>
    <option value="faturacao" shortcut="⌘B">Faturação</option>
    <option value="definicoes" shortcut="⌘S">Definições</option>
  </section>
</go-command>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-command> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <option value="x">Etiqueta</option> é um comando. O campo de pesquisa filtra a lista em tempo real; se não houver correspondência mostra-se uma mensagem de vazio. Ao selecionar, o elemento dispara um evento select com detail.value. Agrupa comandos com <section title="..."> (cabeçalho de grupo, separado automaticamente) e usa shortcut="⌘P" ou disabled em cada option. 

<go-command>
  <section title="Sugestões">
    <option value="novo-ficheiro">Novo ficheiro</option>
    <option value="abrir">Abrir…</option>
  </section>
  <section title="Definições">
    <option value="perfil" shortcut="⌘P">Perfil</option>
  </section>
</go-command>
document
  .querySelector('go-command')
  .addEventListener('select', (e) => {
    console.log(e.detail.value) // 'novo-ficheiro' | 'abrir' | ...
  })

Exemplos

Paleta de comandos

Uma lista de comandos pesquisável. Escreve no campo para filtrar os resultados. 

<go-command>
  <option value="novo-ficheiro">Novo ficheiro</option>
  <option value="abrir-pasta">Abrir pasta</option>
  <option value="guardar-tudo">Guardar tudo</option>
  <option value="fechar-aba">Fechar separador</option>
  <option value="reabrir-aba">Reabrir separador</option>
</go-command>

Item desativado

Marca um comando com o atributo disabled para o tornar não selecionável. 

<go-command>
  <option value="abrir">Abrir…</option>
  <option value="exportar">Exportar</option>
  <option value="publicar" disabled>Publicar</option>
  <option value="definicoes">Definições</option>
</go-command>

Em diálogo

Compõe <go-command> dentro de <go-dialog> para uma paleta de comandos modal, invocável por atalho de teclado.

Abrir paleta de comandos 
<go-dialog>
  <span slot="trigger">Abrir paleta de comandos</span>
  <go-command>
    <option value="ir-inicio">Ir para Início</option>
    <option value="ir-perfil">Ir para Perfil</option>
    <option value="novo-projeto">Novo projeto</option>
    <option value="tema-escuro">Alternar tema escuro</option>
  </go-command>
</go-dialog>
