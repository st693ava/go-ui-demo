Menubar

Um menu visualmente persistente, comum em aplicações de secretária, que dá acesso rápido a um conjunto consistente de comandos.

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-menubar> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section title="..."> torna-se um menu da barra; o title é a etiqueta do botão. As <option value="x"> dentro de cada section são os itens desse menu. Ao selecionar, o elemento dispara um evento select com detail.value. Atributos declarativos opcionais por option: shortcut, disabled, inset, type="separator", type="checkbox" checked, type="radio" name="g" (grupo de opção); uma <section> aninhada dentro de outra vira submenu. 

<go-menubar>
  <section title="Ficheiro">
    <option value="novo">Novo</option>
    <option value="abrir">Abrir</option>
  </section>
  <section title="Editar">
    <option value="copiar">Copiar</option>
  </section>
</go-menubar>
document
  .querySelector('go-menubar')
  .addEventListener('select', (e) => {
    console.log(e.detail.value) // 'novo' | 'abrir' | 'copiar' | ...
  })

Exemplos

Barra de aplicação

Os menus clássicos de uma aplicação de secretária, com vários comandos por menu. 

<go-menubar>
  <section title="Ficheiro">
    <option value="novo">Novo</option>
    <option value="abrir">Abrir</option>
    <option value="guardar">Guardar</option>
    <option value="guardar-como">Guardar como…</option>
  </section>
  <section title="Editar">
    <option value="desfazer">Desfazer</option>
    <option value="refazer">Refazer</option>
    <option value="localizar">Localizar</option>
  </section>
  <section title="Conta">
    <option value="perfil">Perfil</option>
    <option value="definicoes">Definições</option>
    <option value="sair">Terminar sessão</option>
  </section>
</go-menubar>

Item desativado

Marca uma <option> com disabled para a tornar não selecionável dentro do seu menu. 

<go-menubar>
  <section title="Ficheiro">
    <option value="novo">Novo</option>
    <option value="abrir">Abrir</option>
    <option value="guardar" disabled>Guardar</option>
  </section>
  <section title="Ver">
    <option value="zoom-in">Aumentar</option>
    <option value="zoom-out">Reduzir</option>
    <option value="repor" disabled>Repor zoom</option>
  </section>
</go-menubar>
