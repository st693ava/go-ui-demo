Item

Um componente versátil que podes usar para apresentar qualquer conteúdo: título, descrição, media e ações.

  <span slot="description">Um item simples com título e descrição.</span>
  <span slot="actions">
    <go-button variant="outline" size="sm">Ação</go-button>
  </span>
</go-item>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-item> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O <go-item> é self-contained. O título e a descrição passam-se via atributos item-title / item-description (ou slots title / description). A media (ícone, avatar, imagem), as ações, o cabeçalho e o rodapé passam-se via slots nomeados media, actions, header e footer. 

<go-item item-title="Item" item-description="Descrição do item">
  <span slot="media"><!-- ícone / avatar / imagem --></span>
  <span slot="actions">
    <go-button variant="outline" size="sm">Ação</go-button>
  </span>
</go-item>

Exemplos

Variantes

Três variantes: default (fundo transparente), outline (com contorno) e muted (fundo subtil para conteúdo secundário).

Abrir Abrir Abrir 
<go-item item-title="Variante default" item-description="...">
  <span slot="actions"><go-button variant="outline" size="sm">Abrir</go-button></span>
</go-item>
<go-item variant="outline" item-title="Variante outline" item-description="...">
  <span slot="actions"><go-button variant="outline" size="sm">Abrir</go-button></span>
</go-item>
<go-item variant="muted" item-title="Variante muted" item-description="...">
  <span slot="actions"><go-button variant="outline" size="sm">Abrir</go-button></span>
</go-item>

Tamanho

O <go-item> tem tamanhos para diferentes usos: sm para um item compacto, default para um item padrão.

Ação 
<go-item variant="outline" item-title="Item básico"
  item-description="Um item simples com título e descrição.">
  <span slot="actions"><go-button variant="outline" size="sm">Ação</go-button></span>
</go-item>
<go-item variant="outline" size="sm" item-title="O teu perfil foi verificado.">
  <span slot="media"><!-- ícone --></span>
  <span slot="actions"><!-- chevron --></span>
</go-item>

Ícone

Coloca um ícone no slot media para destacar o propósito do item.

Rever 
<go-item variant="outline" item-title="Alerta de segurança"
  item-description="Novo início de sessão detetado...">
  <span slot="media"><!-- caixa de ícone --></span>
  <span slot="actions"><go-button size="sm" variant="outline">Rever</go-button></span>
</go-item>

Avatar

Compõe um <go-avatar> real no slot media para representar uma pessoa.

+ Convidar 
<go-item variant="outline" item-title="Evil Rabbit"
  item-description="Visto pela última vez há 5 meses">
  <span slot="media">
    <go-avatar src="https://github.com/evilrabbit.png" fallback="ER"></go-avatar>
  </span>
  <span slot="actions">
    <go-button size="icon" variant="outline" aria-label="Convidar">+</go-button>
  </span>
</go-item>

Imagem

Coloca uma <img> no slot media para uma miniatura. 

<go-item variant="outline"
  item-title="Midnight City Lights — Electric Nights"
  item-description="Neon Dreams">
  <span slot="media">
    <img src="https://avatar.vercel.sh/Midnight" alt="Midnight City Lights">
  </span>
</go-item>

Grupo

Empilha vários <go-item> numa lista. Usa um <go-separator> entre eles para os delimitar.

+ + + 
<div role="list">
  <go-item item-title="shadcn" item-description="shadcn@vercel.com">
    <span slot="media"><go-avatar src="..." fallback="s"></go-avatar></span>
    <span slot="actions"><go-button variant="ghost" size="icon">+</go-button></span>
  </go-item>
  <go-separator></go-separator>
  <go-item item-title="maxleiter" item-description="maxleiter@vercel.com">...</go-item>
</div>

Cabeçalho

O slot header ocupa a linha inteira do item, acima da media e do conteúdo. 

<go-item variant="outline" item-title="v0-1.5-sm"
  item-description="Tarefas do dia-a-dia e geração de UI.">
  <span slot="header">
    <img src="..." alt="v0-1.5-sm">
  </span>
</go-item>

Link

Envolve o <go-item> numa <a href> nativa para o tornar navegável; os estados de hover e foco aplicam-se à âncora. 

<a href="/docs">
  <go-item item-title="Visita a nossa documentação"
    item-description="Aprende a começar com os nossos componentes.">
    <span slot="actions"><!-- chevron --></span>
  </go-item>
</a>

Dropdown

Compõe cada <go-item> como um item de um <go-dropdown-menu> para uma lista de seleção rica.

Selecionar ▾ 
<go-dropdown-menu>
  <go-button slot="trigger" variant="outline" size="sm">Selecionar ▾</go-button>
  <option value="shadcn">shadcn — shadcn@vercel.com</option>
  <option value="maxleiter">maxleiter — maxleiter@vercel.com</option>
</go-dropdown-menu>

<go-item size="sm" variant="outline" item-title="shadcn"
  item-description="shadcn@vercel.com">
  <span slot="media"><go-avatar src="..." fallback="s"></go-avatar></span>
</go-item>
