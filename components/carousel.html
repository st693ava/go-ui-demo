Instalação

pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-carousel> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section> é um slide. O carrossel insere automaticamente os controlos de anterior/seguinte e suporta arrasto por toque. 

<go-carousel>
  <section>...</section>
  <section>...</section>
  <section>...</section>
</go-carousel>

Exemplos

Tamanhos

Para mostrar vários slides em simultâneo, usa o atributo items-per-view — o <go-carousel> aplica a classe basis-1/N a cada item (equivalente ao basis-* do shadcn-vue). Aqui três itens visíveis, cada um a ocupar um terço da largura.

1
2
3
4
5
 
<!-- 33% da largura do carrossel por item -->
<go-carousel items-per-view="3">
  <section><div class="card">1</div></section>
  <section><div class="card">2</div></section>
  <section><div class="card">3</div></section>
  <section><div class="card">4</div></section>
  <section><div class="card">5</div></section>
</go-carousel>

Espaçamento

No shadcn-vue o espaçamento entre slides faz-se com pl-[VALOR] em cada item e um -ml-[VALOR] negativo no contentor. O <go-carousel> já aplica esse par (pl-4/-ml-4) internamente, por isso o espaçamento entre slides vem por defeito. Para espaço extra dentro de um slide, aplica padding ao conteúdo da própria <section>.

1
2
3
4
5
 
<!-- pl-4/-ml-4 são aplicados internamente -->
<go-carousel items-per-view="3">
  <section>
    <div style="padding:1rem"><div class="card">1</div></div>
  </section>
  <section>...</section>
</go-carousel>

Orientação

Usa o atributo orientation para definir a orientação do carrossel (horizontal por defeito ou vertical).

1
2
3
 
<go-carousel orientation="vertical">
  <section><div class="card">1</div></section>
  <section><div class="card">2</div></section>
  <section><div class="card">3</div></section>
</go-carousel>
