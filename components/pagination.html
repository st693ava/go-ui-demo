Pagination

Paginação com navegação de páginas e ligações anterior e seguinte.

Anterior Command Seguinte Carousel 
<go-pagination
  total="30"
  items-per-page="10"
  default-page="2"
></go-pagination>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-pagination> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

A composição (botões, números e reticências) é resolvida internamente: declara apenas os atributos total (número de itens), items-per-page (itens por página) e default-page (página inicial). Ao mudar de página, o elemento dispara um evento change com detail.page. 

<go-pagination
  total="100"
  items-per-page="10"
  default-page="1"
></go-pagination>
document
  .querySelector('go-pagination')
  .addEventListener('change', (e) => {
    console.log(e.detail.page) // 1, 2, 3, ...
  })

Exemplos

Muitas páginas

Com muitos itens, a lista de páginas colapsa automaticamente em reticências, mantendo a primeira, a última e as vizinhas da atual. 

<go-pagination
  total="500"
  items-per-page="10"
  default-page="5"
></go-pagination>

Poucas páginas

Quando o total cabe em poucas páginas, todas são mostradas sem reticências. 

<go-pagination
  total="30"
  items-per-page="10"
  default-page="2"
></go-pagination>

Itens por página

Ajusta items-per-page para alterar quantos itens cada página comporta — o número total de páginas recalcula-se. 

<go-pagination
  total="200"
  items-per-page="25"
  default-page="1"
></go-pagination>
