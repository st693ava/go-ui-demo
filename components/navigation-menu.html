Navigation Menu

Uma coleção de ligações para navegar em sites.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-navigation-menu> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Cada <section title="..."> é um item da barra. Se a section tiver conteúdo, o title torna-se um trigger que abre um painel com esse conteúdo. Uma section vazia torna-se um link simples sem painel. 

<go-navigation-menu>
  <section title="Produtos">
    <a href="/app">Aplicação</a>
    <a href="/api">API</a>
  </section>
  <section title="Preços"></section>
</go-navigation-menu>

Exemplos

Painel rico

Um item com conteúdo HTML livre no painel — ideal para um menu de destaque com descrição.

Charts Visualizações de dados componíveis para os teus dashboards. Blocks Secções de página prontas a colar. Create Compõe a tua própria interface. 
<go-navigation-menu>
  <section title="Recursos">
    <div class="nm-panel">
      <a href="/charts" class="nm-feature">
        <strong>Charts</strong>
        <span>Visualizações de dados componíveis.</span>
      </a>
      <a href="/blocks">Blocks</a>
      <a href="/create">Create</a>
    </div>
  </section>
</go-navigation-menu>

Links simples

Sections vazias renderizam-se como itens de navegação diretos, sem painel dropdown. 

<go-navigation-menu>
  <section title="Início"></section>
  <section title="Preços"></section>
  <section title="Contacto"></section>
</go-navigation-menu>

Painéis e links combinados

Mistura sections com painel e sections vazias na mesma barra.

Componentes Catálogo go-*. Blocks Secções prontas. 
<go-navigation-menu>
  <section title="Produtos">
    <div class="nm-grid">
      <a href="/components">Componentes</a>
      <a href="/blocks">Blocks</a>
    </div>
  </section>
  <section title="Preços"></section>
