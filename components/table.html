Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-table> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Envolve sempre um <table> real dentro do <go-table>. O parser HTML do browser foster-parenteia qualquer <thead> ou <tr> escrito fora de um <table> antes de qualquer JS correr — por isso o <table> tem de estar presente no markup. O go-table aplica a skin shadcn ao <table> projetado via slot nativo (não aninha outra tabela). Para tabelas ricas com ordenação/paginação usa <go-data-table>. 

<go-table>
  <table>
    <thead>
      <tr><th>Nome</th><th>Cargo</th></tr>
    </thead>
    <tbody>
      <tr><td>Ana</td><td>Programadora</td></tr>
      <tr><td>Rui</td><td>Designer</td></tr>
    </tbody>
  </table>
</go-table>
