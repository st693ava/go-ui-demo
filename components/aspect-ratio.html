Aspect Ratio

Mostra o conteúdo dentro de um rácio de proporção desejado.

Anterior Avatar Seguinte Separator 
<go-aspect-ratio ratio="16/9">
  <img src="..." alt="Fotografia" />
</go-aspect-ratio>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-aspect-ratio> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O atributo ratio aceita uma fração no formato "16/9" ou um número decimal. O conteúdo (tipicamente uma imagem) é projetado e mantém o rácio independentemente da largura. 

<go-aspect-ratio ratio="16/9">
  <img src="..." alt="Imagem" />
</go-aspect-ratio>
<go-aspect-ratio ratio="16/9">
  <img src="..." alt="Imagem" />
</go-aspect-ratio>

Exemplos

Imagem 16:9

Uma imagem apresentada com rácio 16:9 — o exemplo padrão do shadcn-vue, com a moldura arredondada via CSS local. 

<go-aspect-ratio ratio="16/9">
  <img src="..." alt="Fotografia de Drew Beamer" />
</go-aspect-ratio>

Rácios alternativos

Quadrado (1/1) e retrato (3/4) — o mesmo componente, rácios diferentes.

1 : 1
3 : 4
 
<go-aspect-ratio ratio="1/1">
  <div>1 : 1</div>
</go-aspect-ratio>

<go-aspect-ratio ratio="3/4">
  <div>3 : 4</div>
</go-aspect-ratio>
