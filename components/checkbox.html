pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-checkbox> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O conteúdo do elemento é a etiqueta — clicar no texto também alterna o estado. Usa checked para começar marcada. O atributo name liga o valor ao <form> nativo via ElementInternals (FACE). Quando marcado, submete on (ou o value que definires). 

<go-checkbox name="terms">Aceitar termos e condições</go-checkbox>
Aceitar termos e condições 
<go-checkbox name="terms">Aceitar termos e condições</go-checkbox>

Exemplos

Com texto de apoio

Compõe a checkbox com um parágrafo descritivo ao nível da página para dar contexto à escolha. Aqui começa marcada com checked.

Aceitar termos e condições

Ao marcar esta caixa, concordas com os termos e condições. 

<div class="field">
  <go-checkbox name="terms" checked>Aceitar termos e condições</go-checkbox>
  <p class="hint">Ao marcar esta caixa, concordas com os termos e condições.</p>
</div>

Desativada

O atributo disabled impede a interação e remove o valor da submissão do formulário.

Ativar notificações 
<go-checkbox name="notify" disabled>Ativar notificações</go-checkbox>

Cartão

Envolve a checkbox e o texto de apoio numa moldura clicável para um alvo de toque maior.

Ativar notificações

Podes ativar ou desativar as notificações a qualquer momento. 

<div class="card">
  <go-checkbox name="notify" checked>Ativar notificações</go-checkbox>
  <p class="hint">Podes ativar ou desativar as notificações a qualquer momento.</p>
</div>

Num formulário

Como FACE form-input, a <go-checkbox> participa na submissão do <form> nativo pelo seu name — sem JavaScript de ligação.

Aceito os termos Quero receber novidades Submeter {} 
<form>
  <go-checkbox name="terms" required>Aceito os termos</go-checkbox>
  <go-checkbox name="news">Quero receber novidades</go-checkbox>
  <go-button type="submit">Submeter</go-button>
</form>
