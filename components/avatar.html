Avatar

Imagem que representa o utilizador, com fallback quando não carrega.

<go-avatar
  src="https://github.com/shadcn.png"
  alt="@shadcn"
  fallback="CN">
</go-avatar>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-avatar> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define src e alt para a imagem; quando a imagem falha (ou não existe) mostra-se o fallback (também disponível como slot="fallback" para HTML arbitrário). O atributo size aceita sm, default ou lg. 

<go-avatar
  src="https://github.com/shadcn.png"
  alt="@shadcn"
  fallback="CN">
</go-avatar>
<go-avatar
  src="https://github.com/shadcn.png"
  alt="@shadcn"
  fallback="CN">
</go-avatar>

Exemplos

Com fallback

Avatares individuais e um grupo sobreposto — réplica do demo shadcn-vue. O grupo compõe vários <go-avatar> reais com sobreposição negativa via CSS local. 

<go-avatar src="https://github.com/shadcn.png" alt="@shadcn" fallback="CN"></go-avatar>
<go-avatar src="https://github.com/evilrabbit.png" alt="@evilrabbit" fallback="ER"></go-avatar>

<div class="stack">
  <go-avatar src="https://github.com/shadcn.png" alt="@shadcn" fallback="CN"></go-avatar>
  <go-avatar src="https://github.com/leerob.png" alt="@leerob" fallback="LR"></go-avatar>
  <go-avatar src="https://github.com/evilrabbit.png" alt="@evilrabbit" fallback="ER"></go-avatar>
</div>

Apenas fallback

Sem src (ou com imagem indisponível) o avatar mostra as iniciais. Útil para utilizadores sem foto. 

<go-avatar fallback="PS" alt="Pedro Saraiva"></go-avatar>
<go-avatar fallback="GO" alt="go-ui"></go-avatar>

Tamanhos

O atributo size alterna entre sm, default e lg. 

<go-avatar size="sm" src="..." fallback="CN"></go-avatar>
<go-avatar src="..." fallback="CN"></go-avatar>
<go-avatar size="lg" src="..." fallback="CN"></go-avatar>
