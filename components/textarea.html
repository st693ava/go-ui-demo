Textarea

Apresenta uma área de texto de formulário ou um componente com o aspeto de uma.

Anterior Input Seguinte Slider 
<go-textarea name="message" placeholder="Escreve a tua mensagem aqui."></go-textarea>

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-textarea> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define placeholder para o texto-guia. O name liga o valor ao <form> nativo via ElementInternals (FACE); required faz a validação viver no host. 

<go-textarea name="message" placeholder="Escreve a tua mensagem aqui."></go-textarea>
<go-textarea name="message" placeholder="Escreve a tua mensagem aqui."></go-textarea>

Exemplos

Por defeito

Uma área de texto simples.

<go-textarea name="message" placeholder="Escreve a tua mensagem aqui."></go-textarea>

Desativada

Uma área de texto desativada: o atributo disabled impede a edição e remove o valor da submissão. 

<go-textarea name="message" placeholder="Escreve a tua mensagem aqui." disabled></go-textarea>

Com etiqueta

Uma área de texto com etiqueta: compõe <go-label> com <go-textarea> ao nível da página.

A tua mensagem 
<go-label for="msg">A tua mensagem</go-label>
<go-textarea name="msg" placeholder="Escreve a tua mensagem aqui."></go-textarea>

Com texto de apoio

Uma área de texto com texto de apoio: adiciona uma descrição abaixo do campo para dar contexto.

Bio

Esta descrição será visível no teu perfil público. 

<go-label for="bio">Bio</go-label>
<go-textarea name="bio" placeholder="Conta-nos um pouco sobre ti."></go-textarea>
<p class="hint">Esta descrição será visível no teu perfil público.</p>

Com botão

Uma área de texto com botão: compõe o campo com um <go-button> de envio ao nível da página.

Enviar mensagem 
<go-textarea name="msg" placeholder="Escreve a tua mensagem aqui."></go-textarea>
<go-button type="submit">Enviar mensagem</go-button>
