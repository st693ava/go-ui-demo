Empty

Usa o componente Empty para mostrar um estado vazio.

Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-empty> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Define empty-title e empty-description via atributos. A media (ícone, avatar) vai no slot="media"; o conteúdo da ação (botões, input) vai no slot por defeito (sem atributo slot) — projeta a instância viva, necessário para componentes interativos como <go-button>. Usa media-variant="icon" para a moldura quadrada do ícone. 

<go-empty
  media-variant="icon"
  empty-title="Sem dados"
  empty-description="Não foram encontrados dados."
>
  <span slot="media"><svg><!-- ícone --></svg></span>
  <div>
    <go-button>Adicionar dados</go-button>
  </div>
</go-empty>

Exemplos

Contorno

Usa a classe utilitária border para criar um estado vazio com contorno tracejado.

Carregar ficheiros 
<go-empty
  class="border border-dashed"
  media-variant="icon"
  empty-title="Armazenamento cloud vazio"
  empty-description="Carrega ficheiros para o teu armazenamento cloud para lhes aceder em qualquer lado."
>
  <span slot="media"><svg><!-- ícone nuvem --></svg></span>
  <div>
    <go-button variant="outline" size="sm">Carregar ficheiros</go-button>
  </div>
</go-empty>

Fundo

Usa os utilitários bg-* e bg-gradient-* para adicionar um fundo ao estado vazio.

Atualizar 
<go-empty
  class="from-muted/50 to-background h-full bg-gradient-to-b from-30%"
  media-variant="icon"
  empty-title="Sem notificações"
  empty-description="Estás em dia. As novas notificações aparecem aqui."
>
  <span slot="media"><svg><!-- ícone sino --></svg></span>
  <div>
    <go-button variant="outline" size="sm">Atualizar</go-button>
  </div>
</go-empty>

Avatar

Usa o slot="media" para mostrar um avatar no estado vazio, com a variante default (sem moldura de ícone).

Deixar mensagem 
<go-empty
  empty-title="Utilizador offline"
  empty-description="Este utilizador está offline. Podes deixar uma mensagem ou tentar mais tarde."
>
  <span slot="media">
    <go-avatar class="size-12 grayscale" src="..." fallback="ZN"></go-avatar>
  </span>
  <div>
    <go-button size="sm">Deixar mensagem</go-button>
  </div>
</go-empty>

Grupo de avatares

Usa o slot="media" para mostrar um grupo de avatares no estado vazio.

Convidar membros 
<go-empty
  empty-title="Sem membros na equipa"
  empty-description="Convida a tua equipa para colaborar neste projeto."
>
  <span slot="media">
    <span class="flex -space-x-2 *:size-12 *:ring-2 *:ring-background *:grayscale">
      <go-avatar src="..." fallback="AA"></go-avatar>
      <go-avatar src="..." fallback="SB"></go-avatar>
      <go-avatar src="..." fallback="ZN"></go-avatar>
    </span>
  </span>
  <div>
    <go-button size="sm">Convidar membros</go-button>
  </div>
</go-empty>

InputGroup

Podes adicionar um <go-input-group> no slot por defeito — útil para um estado 404 com pesquisa. 

<go-empty
  empty-title="404 - Não encontrado"
  empty-description="A página que procuras não existe. Tenta pesquisar o que precisas."
>
  <div class="w-full">
    <go-input-group class="sm:w-3/4">
      <input slot="input" type="text" placeholder="Tenta pesquisar páginas..." />
      <svg slot="prefix"><!-- ícone lupa --></svg>
    </go-input-group>
  </div>
</go-empty>
