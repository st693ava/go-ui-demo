Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-popover> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

O slot="trigger" é o botão que abre o popover (projeta no lugar). O conteúdo é o slot="content" — ou, em alternativa, qualquer markup sem slot, que é usado como conteúdo por defeito. 

<go-popover>
  <go-button slot="trigger">Abrir</go-button>
  <div slot="content">Coloca aqui o conteúdo do popover.</div>
</go-popover>

Conteúdo por defeito

Sem slot="content", qualquer markup que não seja o gatilho é usado como conteúdo do popover (defaultHtml).

Atualizações

Tens 3 notificações por ler. Vê-as na tua caixa de entrada.
