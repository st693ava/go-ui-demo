Instalação

npm i github:st693ava/go-ui-web-components
pnpm add github:st693ava/go-ui-web-components
yarn add github:st693ava/go-ui-web-components
bun add github:st693ava/go-ui-web-components

Importa o registo uma vez no teu entry-point — regista todos os Custom Elements, <go-sheet> incluído: 

// main.ts / app.js
import '@st693ava/go-ui'
import '@st693ava/go-ui/style.css'

Uso

Como o <go-drawer>, usa regiões nomeadas por slot: trigger (projeta no lugar e abre), title, description, content e footer. O atributo side controla de que margem o painel desliza — right (default), left, top ou bottom. 

<go-sheet>
  <go-button slot="trigger">Abrir</go-button>
  <div slot="title">Tens a certeza absoluta?</div>
  <div slot="description">
    Esta ação não pode ser anulada. Vai apagar permanentemente a tua conta.
  </div>
</go-sheet>

Exemplos

Lados

Usa o atributo side para escolher a margem de onde o painel desliza: top, right, bottom ou left.

Topo
Painel superior
Desliza a partir do topo.
 Direita
Painel direito
Desliza a partir da direita.
 Fundo
Painel inferior
Desliza a partir do fundo.
 Esquerda
Painel esquerdo
Desliza a partir da esquerda.
 
<go-sheet side="top">…</go-sheet>
<go-sheet side="right">…</go-sheet>
<go-sheet side="bottom">…</go-sheet>
<go-sheet side="left">…</go-sheet>
